# M8 計画: 文明の発生と段階、負荷、輝石 — シナリオ「塔の重さ」

**Goal:** 島に文明が芽生え、段階を上げるほど島を弱らせる仕組みを入れ、「塔の重さ」を星の力の制約下で遊べるようにする。
**根拠:** `docs/design/2026-09-19-scenarios-and-world.md` §1.2(輝石)、§1.5(文明仮説)、§5 逆算表の 4。信仰・祈り(5)と回避装置(6)は M9 以降。
**選んだシナリオ:** #23 塔の重さ。文明の負荷と生気だけで成立し、信仰が要らない。

## 1. 完了条件

| # | 条件 | 検証 |
|---|---|---|
| G1 | 安定して餌に余剰がある種に文明が芽生え、輝石を掘って段階が上がる | 単体テスト |
| G2 | 段階が上がるほど森と生気が減る(負荷)。餌か生気が尽きると段階が下がり、巣まで落ちれば崩壊 | 単体テスト |
| G3 | 塔の重さ: 放置と素朴戦略は dead、力を配分する 2 通りは alive | `tests/slow` |
| G4 | 文明の段階・進み・集落が画面で読める。輝石レイヤーがある | E2E + 手動 |
| G5 | 手動で 3 回遊び 1 回は負け、理由が石板で分かる | プレイ記録 |

## 2. 設計(決定)

### 2.1 輝石(crystal)層
- `World` に `crystal: Float32Array` [0,1]。地形生成時に決定論ノイズの閾値で陸に鉱脈の塊を置く(霊脈の線は M10 以降。今は塊だけ)。海は 0。
- 掘られると減る。再生しない(生気→輝石の再生は世界観にあるが今回は入れない)。
- レイヤー「輝石」、セル詳細に輝石。保存に含める。

### 2.2 文明(civilization)
- 1 島 1 文明。`WorldConfig.civilization?: { speciesId: string }`(知性を持ちうる種。既定は鹿)。シナリオの `start.civilization` で初期段階と集落の位置を上書きできる。
- 状態: `stage`(0 = なし、1 巣、2 火、3 歌、4 石、5 帆、6 塔、7 星)、`progress` [0,1)、`home`(集落セル)、`population`(集落半径内のその種の総量)。
- **発生**: `stage 0` のとき、年に 1 回、その種の直近 10 年の年次総量の振幅比 < 0.15(既存 `amplitudeRatio`)かつ集落候補セル(その種の密度が最大のセル)の半径 r 内で植生 > 0.4 なら `stage 1`。
- **段階を上げる**: 毎 tick、`home` 半径 `MINE_RADIUS[stage]` 内の輝石を `MINE_RATE[stage]` だけ掘り、掘った量を `progress` に足す。`progress ≥ NEED[stage]` で次の段階。輝石が尽きれば上がらない。
- **負荷**: 半径 `LOAD_RADIUS[stage]` 内で毎 tick 森を `LOGGING[stage]` 減らし(枯死に積む)、生気を `VITALITY_DRAIN[stage]` 減らす。段階が上がるほど半径と量が増える。
- **衰退と崩壊**: 年に 1 回、`population` が段階の必要量 `POP_NEED[stage]` 未満、または集落半径内の生気平均 < 0.1 なら `stage − 1`(`progress` 0)。`stage 1 → 0` で崩壊(ログ `sim.civ.collapsed`)。
- ログ: `sim.civ.emerged`、`sim.civ.stage`(上下)、`sim.civ.collapsed`。`sim.tick.summary` に `civStage`。
- 純粋関数 `stepCivilization(state, layers, config)` を `src/simulation/civilization.ts` に置き、World は呼ぶだけ。係数は全て同ファイルの定数(校正で動かす)。

### 2.3 表示
- SceneView: 集落に段階数だけ積んだ小さな箱(InstancedMesh)。段階で高さが増える。
- HUD 左上に「文明 塔(6)・進み 40%・民 12」。セル詳細に輝石。石板の年表に段階の上下。
- レイヤー列に「輝石」。

### 2.4 シナリオ「塔の重さ」
- 予言: 「この島の民は塔を建てた。塔は森を伐り、生気を吸う。放っておけば森は尽き、塔は民ごと崩れる。百年、森を三割保ったまま塔を立たせ続けよ。民を減らせば塔は軽くなるが、減らしすぎれば崩れる。」
- 開始: 文明「塔」(stage 6)、集落は島の中心付近、輝石は少なめ(星に上がる余地はない)。予算あり。
- alive(100 年目): `all [ forest の総量 ≥ 開始の 0.3 倍 (baselineYear 0), civ_stage ≥ 6 (直近 10 年の最小) ]`。
- dead: 文明崩壊(`civ_stage 0`)。
- 想定するジレンマ: 森を放つ(力)か、雨で森を育てる(維持費)か、疫病で民(鹿)を減らして負荷を下げるか(減らしすぎれば衰退)。
- 判定条件の追加: `civ_stage { min?, max?, years? }`(直近 years 年の最小段階)。警告: `civ_declining`(段階が下がった年)。
- 校正の判定行列: 放置 dead / 森の放流だけ dead / 疫病だけ dead / 雨 + 放流 alive / 疫病で民を間引き + 放流 alive。

## 5. リスク
- 文明が芽生えない/すぐ崩壊する: 発生条件と `POP_NEED` は既定の島(seed 42、size 64)で先に測ってから決める。
- 負荷が強すぎて他の 5 本が壊れる: 既存シナリオは `civilization` を設定しない(文明なし)。既定の世界も文明なし。
- 通し実行が伸びる: 塔の重さの 5 ケースで +5 分。
