# デザインボード(観察画面・空の舟)の決定原稿

観察画面(M22)の見た目の物差しになる絵です。3D アセットとシェーダは、ここにある絵との比較画(同じ向き・同じ光で並べる)で合否を取ります。
方向性の決定は `docs/design/2026-09-23-observation-view.md`、レビューに使ったボードは https://claude.ai/artifact/ELLA1JjBSgZz5PeXTjaWs3(非公開)。

## 申し送り: 世界観が衝突したら動物側を優先する

**動物 3 種(`creatures/`)の世界観が最上位です。** キービジュアルと他の基準画(`key-visuals/`・`sheets/`)は、動物の画風と揃っていません
(キービジュアルの鹿は自然な鹿、植物・集落・舟・地面・演出は動物の意匠を知らずに描いた第 1 稿)。
今後の絵・モデル・シェーダで両者が食い違ったら、**動物側のムー意匠を正とし、他を動物側に寄せて直す**(2026-09-23、ユーザー指示)。

動物側の世界観の要点(元の参照 `assets/textures/concept/*-angular.png` 由来):

- 月鹿: 黄褐色の体に青緑の装甲板、光るシアンの継ぎ目、シアンに光る三日月の角と目。民は角の付け根に細い紐を結ぶだけ
- 灰狼: 珊瑚色の体、背のシアンの稜線、低い構え
- 土兎: 砂色の体、焦げ茶の耳先、光る六角の紋と目
- 共通: 角ばった面を丸めた形に、柔らかい絵画の陰影と、シアンの発光(ムーの遺産の光)

## 出どころ

- 生成: `tools/gen-design-board.mjs`(プロンプト全文あり)。キービジュアルと `sheets/` は `gemini-2.5-flash-image`、
  `creatures/` は `gemini-3-pro-image-preview` に元の参照画(`assets/textures/concept/*-angular.png`)とキービジュアル(群れ)を渡して描いたもの。
- 生成物は `assets/textures/board/drafts/`(コミットしない)に出る。承認したものだけを手でこの構成に移し、この表の状態を更新する。
- 画像は PNG のまま Git LFS(`.gitattributes` の `*.png`)。AI 生成画像なので、利用は Google の生成 AI の利用規約に従う。

## 次に直すもの

- `sheets/` の 6 枚を、動物側の意匠(シアンの発光・丸めた角ばり・同じ陰影)に寄せて描き直す(M22-01 の残り、または M22-02 の試作と並行)。
- キービジュアルは物差しとしてはこのまま使う。描き直す場合は鹿を `creatures/` の造形に差し替える。
