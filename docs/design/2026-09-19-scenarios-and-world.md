# シナリオ層と世界観 — 「潮の環(しおのわ)」

- 作成日: 2026-09-19
- 位置づけ: 勝敗なしの本体(M1〜M3)の上に被せる **シナリオ層** の設計素材。
  ここから必要なシステムを逆算する(§5)。実装計画ではない。
- 方針: リアルの生態学を土台にしつつ、ゲームとフィクションの自由度で「未知の資源」「空想の生き物」「信仰」「文明仮説」を足す。
  ただし **どの要素も本体の数値モデル(密度・気候・フィードバック・ログ)に接続できる形** で定義する。

---

## 1. 世界観「潮の環」

### 1.1 世界の形

温かい海に無数の島が浮かび、島は長い年月をかけて **環(わ)** と呼ばれる大きな海流に乗って漂う。
一つの島は一つのビオトープ。島どうしは普段は隔たっているが、環の周期(数百年)で近づき、生き物と資源が渡る。
プレイヤーは島を見守る **「潮見(しおみ)」**。島の生き物からは、雨や火や新しい命をもたらす気配として感じられている。

本体との対応: 「一枚の島」が舞台の単位。「隣の島」はシナリオ間の持ち越し(種・資源)を説明する装置。

### 1.2 未知の資源(架空だが数値で定義する)

| 資源 | 何か | 本体での扱い | 効く先 |
|---|---|---|---|
| **生気(せいき)** | 土と水に溶けた生命の残滓。死骸と落ち葉が土に還るとき生まれ、根と流れを伝って移動する | セルの `vitality` 層 [0,1]。死亡・被食・山火事で増え、植物の成長が消費し、隣接へ拡散。ゆっくり減衰 | 植物の成長率。**物質循環の閉じ**。枯渇すると「生気枯れ」 |
| **星砂(ほしずな)** | 隕石が運ぶ淡く光る砂。生気を爆発的に増やすが、多すぎると土を焼く | 隕石災害でセルに堆積。`vitality` の生産を上げ、閾値を超えると植物の適合度を下げる | **豊かにしすぎると崩壊する**(enrichment のパラドックス)を触れる形にする |
| **潮霧(しおぎり)** | 海から陸へ流れ込む霧。雨の源 | 海岸からの距離で `moistureBase` を持ち上げる。風向きは季節で変わる | 内陸の乾燥、海岸の湿潤。地形変更(山)で遮れる |
| **琥珀(こはく)** | 森が長く続いた土地に残る記憶の結晶。過去の島の状態を封じている | 森密度が N 年連続で高いセルに生成。文明が採取して「記憶」を得る | 文明の技術段階、プレイヤーへの履歴表示(ログの可視化と結びつける) |
| **霊脈(れいみゃく)** | 島の下を走る生気の大動脈。地形の裂け目で地表に出る | 地形生成時に数本の線として置く。線上のセルは `vitality` の減衰が遅い | 森の回廊、聖地、文明の発祥地 |

### 1.3 空想の生き物(本体の 3 階層 + 分解者 + 特殊枠)

| 生き物 | 階層 | 性質(数値化の当たり) |
|---|---|---|
| **月草(つきくさ)** | 植物 | 乾燥に強く、夜に生気を吸う。草の上位互換だが星砂に弱い |
| **鐘樹(かねぎ)** | 植物 | 森。落葉が生気を多く生む。100 年立つと琥珀を作る |
| **胞子苔(ほうしごけ)** | 分解者 | 死骸を生気に変える速度を上げる。湿潤でのみ生きる。山火事で全滅 |
| **月鹿(つきじか)** | 草食 | 鹿。季節で南北に渡る(拡散率が季節で変わる) |
| **土兎(つちうさぎ)** | 草食 | ウサギ。乾燥地。爆発的に増え、生気を食い荒らす |
| **石喰い(いしくい)** | 草食(鉱物食) | 星砂を食べて減らす唯一の生き物。ゆっくり増える。星砂の解毒係 |
| **灰狼(はいおおかみ)** | 肉食 | 狼。群れで動く(拡散率が高い) |
| **炎蜥蜴(ほのおとかげ)** | 肉食 | 火山の熱(`heat`)がある場所でしか繁殖できない。火山が冷えると消える |
| **歌鳥(うたどり)** | 特殊 | 種子を運ぶ。植物の拡散率を上げる。捕食されない代わりに個体数は森の量で決まる |
| **浮き草鯨(うきくさくじら)** | 特殊(海) | 海岸に養分を運ぶ。沿岸セルの生気を上げる。海が温まりすぎると去る |
| **夢喰い(ゆめくい)** | 頂点 | 知性を持つ生き物だけを食べる。文明が生まれると現れる。信仰で退けられる |

### 1.4 信仰

知性が芽生えた種は、プレイヤーの介入(雨、火、新しい命)を **兆し** として受け取り、解釈を積み重ねる。

- 介入のログ(`cmd.*`, `sim.disaster`)がそのまま **神話の素材** になる。「大火の年」「鹿が降った年」。
- 信仰は種ごとの `faith` 値 [0,1]。プレイヤーの介入が **予測可能**(同じことをすると同じ結果)だと上がり、気まぐれだと下がる。
- 高い信仰は **祈り** を生む: 島のどこかに「祈りの印」が現れ、プレイヤーに要求が届く(「雨を」「狼を減らして」)。応えると信仰が上がり、無視すると下がる。
- 信仰は文明の安定度に効く。低いと内乱(人口の自壊)、高いと夢喰いを退ける。
- 信仰は勝敗にも使える: 「一度も祈りに応えずに文明を存続させる」「祈りに全て応えた結果を見る」。

### 1.5 文明仮説「知性は余剰から生まれる」

SimEarth の「どの分類群も知性を持ちうる」を引き継ぐ。ただし条件を **本体の数値** で置く。

- ある種の総量が **N 年連続で安定**(年次振幅比 < 0.15)し、かつその種のセルの **餌に余剰**(食べ残しが平均 30% 以上)があると、その種は **「巣の時代」** に入る。
- 以後、7 つの段階を上がる: **巣 → 火 → 歌 → 石 → 帆 → 塔 → 星**。
  各段階の条件は本体の資源で書く(火: 森の量、歌: 琥珀、石: 霊脈上の居住、帆: 海岸の占有、塔: 生気の余剰、星: 星砂の蓄積)。
- 文明は島に負荷をかける: 段階が上がるほど生気の消費と森の伐採が増え、**自分の土台を食う**。
  ここが SimEarth 的な「文明は生態系を壊す」の再現であり、多くのシナリオの障害になる。
- 知性を持つ種は **月鹿でも土兎でも狼でもよい**。狼の文明は肉食のため草食獣に依存し、土兎の文明は爆発と飢餓を繰り返す。種によって文明の性格が変わる。

## 2. シナリオの形式

各シナリオは次を持つ。

- **開始状態**: 島の初期条件(シード、種、資源、時代)
- **Alive(生存条件)**: これを満たしている間は続く / 達成で勝利
- **Dead(敗北条件)**: これが起きたら終わり
- **障害**: 途中で必ず起きる、または起きやすい出来事(3 つ)
- **必要システム**: 本体に足す必要のあるもの(§5 で集計)

プレイヤーの体験は「Alive を守りながら Dead を避ける」。両方が **本体のログ・イベント** で判定できることを条件にする。

## 4. 「面白い」の根拠(シナリオ設計の原則)

1. **Alive と Dead は両方ともログのイベントで判定できる**。人が「なぜ負けたか」を追える。
2. **障害は本体のダイナミクスから自然に出るもの**を優先する(狼の初期爆発、振動の谷、山火事の延焼)。台本の障害は「環」「隕石」など理由のあるものに限る。
3. **矛盾する要求**を入れる(22 の祈り、25 の塔と森、27 の豊かさ)。プレイヤーが選ぶ余地が生まれる。
4. **不介入も選択**にする(5, 21, 29)。「見守る」ゲームの本質を勝敗にする。
5. **結果を持ち越す**(18, 30)。島が「自分の島」になる。
6. リアルとフィクションの境界は「数値で定義できるか」。生気も信仰も本体の層として置けるので、生態学の式と同じ扱いにできる。
