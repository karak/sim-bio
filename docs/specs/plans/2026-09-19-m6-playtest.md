# M6 手動受入プレイテスト: 「沈む欠片」

2026-09-19。ブラウザ(Chrome、`vite preview` のビルド済み配信、size 64)で 3 回遊んだ記録。操作は Chrome DevTools 経由でスライダー・チップ・島のクリックを実際の UI イベントとして送った。

## チェックリスト

- [x] 予言・節目・力の残量が最初から石板に見える
- [x] 雨を入れると「維持 −N/年」と、収入を超えれば警告が出る
- [x] 力が尽きると雨が止まり、石板の力が 0 になる
- [x] 鹿が減ると警告が出る
- [x] 勝敗に内訳(介入回数・使った力・陸地率・総量)が出る
- [x] 少なくとも 1 回は負け、理由が石板の文言で分かる

## 1 回目: 雨 1.5 倍を 30 年目に入れて放置 — 島は滅びた

| 年 | 力 | 収入 / 維持 | 石板 |
|---|---|---|---|
| 30 | 120 / 120 | +5.6 / −0.0 | 節目 3 つ |
| 30 直後 | 118 | | 雨 ×1.5 を入れた(値段 2) |
| 89 | 115 | +2.4 / −0.0 | ⚠ 陸が減っている(基準の 30%)。**雨はすでに止まっていた**(力が尽きて既定に戻った) |
| 90 | 118 | +2.3 / −0.0 | ⚠ 鹿が減っている(基準の 16%) |
| 100 | 120 | +1.9 | ⚠ 鹿 19%、ウサギ 10%、陸 24% |

結果: **島は滅びた / 予言の年に条件を満たせず: 群れが小さい(10 年平均): 鹿 5.1 (< 6.0)**。内訳: 介入 1 回 · 使った力 2 · 陸地率 6% · 鹿 4 · ウサギ 2 · 狼 6。

- 悩んだ点: 雨を入れた直後は力が 120 もあり余裕に見える。維持 10/年 > 収入 5.6/年 なので 20 年ほどで尽きるが、その間に何も考えず放置してしまう。
- 分かりにくかった点: **雨が止まった後もスライダーが ×1.5 のまま**だった(世界の気候は 1.0)。→ 修正: スライダーを毎フレーム世界の気候に同期(ドラッグ中は除く)。刻みも 0.1 → 0.05(1.25 が選べる)。
- 分かりにくかった点: 力が尽きた瞬間は石板が揺れるだけで、100 倍速では見逃す。→ 記録に残す(石板の警告は年次評価なので「力が足りない」は翌年に出る)。M7 候補: 年表(出来事のログ)。

## 2 回目: 雨 1.25 倍 + 高地に鹿・兎を放つ(想定解 1) — 島は生き延びた

| 年 | 力 | 収入 / 維持 | 操作・石板 |
|---|---|---|---|
| 15 | 120 / 120 | +6.8 | 力が上限に達した(以後 30 年目まで収入を捨てている) |
| 30 | 120 | +5.6 / −5.0 | 雨 ×1.25 を入れた |
| 40 | 120 → 112 | +5.1 / −5.0 | 一時停止し、住みやすさレイヤー(鹿)で高地を確認して鹿を 2 か所に放った(8) |
| 50 | 109 | +4.5 / −5.0 | ⚠ 維持費が収入を超えている |
| 60 | 101 → 93 | +4.0 / −5.0 | 島が 3 つに割れた。北の高地に鹿、兎を放った(8) |
| 80 | 61 → 53 | +2.8 / −5.0 | ⚠ 陸 36%。鹿・兎を放った(8) |
| 85〜95 | 41 → 14 | | ⚠ ウサギが減っている(基準の 23% → 19%) |
| 100 | **0** | +1.9 / −5.0 | ⚠ 力が足りない(残り 0) |

結果: **島は生き延びた / 群れが残った(10 年平均): 鹿 10.4 / ウサギ 8.2 / 狼 6.3**。内訳: 介入 7 回 · 使った力 26 · 陸地率 6% · 鹿 7 · ウサギ 14 · 狼 5。

- 悩んだ点: 力が 100 年目にちょうど 0 になった。80 年目の放流(8)をためらう場面が本当にある。雨を 1.3 にしていたら(スライダーの刻みが 0.1 だった)維持 6/年で 90 年目に尽きていた。
- 悩んだ点: 前半 15 年で上限に達し、30 年目まで収入を捨てていた。「早く使うか貯めるか」が上限で強制されるのは意図どおりだが、上限に達したことを石板が告げない。→ M7 候補: 上限到達の警告。
- 分かりにくかった点: 種ごとの**現在の数**が数字で見えない(グラフだけ)。狼が鹿の 1.5 倍を超えたら疫病、という判断ができない。→ 修正: 凡例に現在の総量を年次で表示。
- 分かりにくかった点: 一時停止中にスライダーを動かすと、世界に反映される前に(初版の同期処理が)値を戻してしまった。→ 修正: 世界の気候が**変わったときだけ**スライダーを追従させる。

## 3 回目: 前半は貯め、60 年目に雨 1.4 倍 + 鹿の種まき(想定解 2) — 島は生き延びた

| 年 | 力 | 収入 / 維持 | 操作・石板 |
|---|---|---|---|
| 60 | 120 → 110 | +4.0 | 雨 ×1.4(2)と鹿を 2 か所(8) |
| 65 | 89 | +3.7 / −8.0 | ⚠ 陸 47%、維持費が収入を超えている |
| 80 | 17 | +2.8 / −8.0 | |
| 85 | 2 | +2.6 / −0.0 | **力が尽きて雨が止まった**(スライダーも ×1.00 に戻った。1 回目の修正が効いている) |
| 95 | 25 | +2.1 | ⚠ ウサギが減っている(基準の 12%) |
| 100 | 35 | | |

結果: **島は生き延びた / 群れが残った(10 年平均): 鹿 13.8 / ウサギ 22.1 / 狼 8.3**。内訳: 介入 3 回 · 使った力 10 · 陸地率 6% · 鹿 12 · ウサギ 32 · 狼 7。

- 悩んだ点: 雨 1.4 は 25 年しか持たなかった。1.5 なら 20 年で、ヘッドレスの校正では滅びる。「どこまで強く降らせるか」が効いている。
- 補足(ヘッドレスの校正から): 雨なしで 70 年目以降に鹿を放つだけの案は鹿の 10 年平均 3.4 で滅びた。雨と種まきを同時にするのが要点。住みやすさレイヤーで帯が上がるのを確認してから放つ。

## まとめ

- 3 回中 1 回負け(1 回目)、理由は石板の文言「群れが小さい(10 年平均): 鹿 5.1 (< 6.0)」で分かる。G5 達成。
- 直した表示: スライダーの世界への同期(力切れで雨が止まったのが見える)、雨の刻み 0.05、凡例の現在数。
- M7 候補: 力が上限に達したときの警告、出来事の年表(力切れの瞬間を後から読める)、石板の警告のうち「陸が減っている」は沈む欠片では常に出るので抑える(予言どおりの進行は警告にしない)。
- 環境メモ: dev サーバー(HMR)でプレイ中にソースを編集するとページが再読み込みされてプレイが消える。プレイテストは `npm run build && npx vite preview` で配信したビルドで行う。
