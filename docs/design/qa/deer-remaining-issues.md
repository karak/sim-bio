# 光角鹿 (deer) 3D モデル 残課題

対象: `assets/models/deer.glb` / `.blend`、`tools/blender/deer.py`。中間成果物として利用する。
到達値 (平行投影 az 135° / el 10°): シルエット IoU 0.73、fur / dark / glow マスク IoU 0.72 / 0.52 / 0.39、色 ΔE76 は全パーツ < 1 (`deer-metrics.json`)。
初版 (透視 50 mm) からの変化: シルエット 0.49 → 0.73、dark 0.31 → 0.52、glow 0.21 → 0.39。

## 解消した課題 (2 回目)

- **角が太い三日月になっていない** → 参照クラス図の左右の角の対応点から 3D 折れ線を復元した (`make_antler` のコメントに換算式)。
  根元 (深緑) は頭頂から外へほぼ水平の帯、発光の主幹は 13 点の折れ線で外へ開きながら後ろ上へ掃き、上で前へ戻って先端が上を向く。
  前向きの枝 2 本 (内側 C・外側 B) と内側後ろ向きの枝 A。半径は根元 0.042 → 先端 0。
- **深緑パネルの境界がジグザグ** → `Kit.cut_along` を追加。参照座標の多角形の各辺を通る視線 2 本が張る平面で、辺の近くの面だけを bisect してから塗る。
  境界が直線になり dark IoU 0.31 → 0.52。パネルの輪郭は参照クラス図の dark 画素を fy 0.02 刻みで読んだ値。腰パネルは手前の後脚の腿にもかける。
- **脚の位置と胴の形** → 参照では前脚は胸の前面より 0.28 m 後ろ (y≈+0.05)、後脚は腿から飛節へ後ろに傾く。背はき甲から尻へ 0.08 m 下がる。
  胸の前面は狭く、首の付け根も細く。脚の幅 0.05 m。これで fur IoU 0.42 → 0.72。
- **頭が小さい** → 頭頂を平らに、鼻梁を高く、鼻先まで太いブロックにした (fy 0.37〜0.47 に fx 0.03〜0.195)。
- **評価の透視歪み** → wolf と同じく平行投影で評価 (透視 0.49 → 平行投影 0.52、形状修正前)。生成側のデカール投影も平行投影。

## 残っている課題

### 1. glow IoU 0.39 (目標 0.50)
- 参照の奥側 (右) の角は手前より 35% 細く描かれている (奥行きの表現)。モデルは左右同じ太さなので奥の角が太く写る (fy 0.06〜0.14 で幅 0.031 vs 0.02)。
- 手前の角の上端は参照よりわずかに内側 (fy 0.06 で fx −0.135 vs −0.153)。
- 対処案: 参照どおり奥の角の半径を 0.7 倍にする (左右非対称になる) か参考値とする。主幹上部の x を +0.02。

### 2. シルエット IoU 0.73 (目標 0.80)
- 残差: 胸の前面がまだ 0.02 H 前に出る (fy 0.60 で fx 0.161 vs 0.143)。手前の後脚の腿が 0.03 H 後ろに張る。
  頭頂と耳の間の隙間 (参照 fx 0.039〜0.049) がない。き甲〜腰の背の線が 0.01〜0.02 H 高い。
- 対処案: 胸の前面の断面を y −0.17 へ、腿の上端の ry を 0.09 に。耳を細く立てる。

### 3. dark の面積比 +0.007、重心 0.015 は達成。角の根元の形
- 参照の根元は頭頂から外へ伸びる細い帯だが、モデルは枝の付け根 (z < 1.205) をまとめて深緑にしているので塊に見える。
- 対処案: 深緑を根元のチューブだけにし、枝の付け根は発光のまま。dark の面積比が −0.01 ほど動く。

### 4. 目・口・耳の細部 (T8)
- 参照の目は菱形に深緑の縁取り。現状はアーモンド形 2 層デカール。口の線 (dark の細い線) は未実装。耳は参照より小さい (0.24 → 0.28)。

### 5. 収束色は比較スクリプトの照明前提
- rabbit と同じ (`rabbit-remaining-issues.md` #7)。glow は発光強度 0.3、平行投影で撮影。

### 6. 三角形数 2805 (上限 3000 に近い)
- `cut_along` で胴の面が増えた。パネルの多角形の頂点を減らす (肩 11 → 8、腰 12 → 8) と 200 前後減る。
