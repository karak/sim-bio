## AC2 の手順

1. `pnpm run dev` を起こし、Chrome で `http://localhost:5173/?scenario=sky-ship` を開く
2. 「3D で見る」を押す。下の帯が「観察中 自動カメラ」になる
3. 開発者ツールの Console で次を貼る。ショットが変わるたびに、種類と理由が出る
   ```js
   let last = ''; setInterval(() => { const s = __probe.observe?.stats(); if (s && s.camera !== last) { last = s.camera; console.log(document.querySelector('#observe-layer .o-stats').textContent, s.camera); } }, 500);
   ```
4. 下の帯の 10x で進める(時間を詰めるなら、Console で `document.querySelector('#speed-100').click()`)。理由が `:scene` の行が場面の引き金で切り替わったショット。種類が `coastWide`(海岸の引き)・`shipLookUp`(舟を見上げる)・`settlementHigh`(集落の俯瞰)・`groveTrack`(林の横移動)のどれか
5. 見るのは 2 つ。`:scene` の行で画面が実際にその画に切り替わるか。その画が場面(雨・飛び立ち など)を映しているか
6. 帆を失う・芽吹きは空の舟を流すだけでは起きなかった(今日の 98 年)。芽吹きは操作画面の石板で種をまく介入、帆を失うは舟が出る前に文明の段が落ちる島で起きる。どの島・どの年で起きるかは確かめていない
