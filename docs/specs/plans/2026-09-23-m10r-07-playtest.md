# M10R-07 手動受入プレイテスト: 「祈りに応えるな」の作り直し(若い信仰の記憶・北の谷の狼・谷への先回り)

2026-09-23。ブラウザ(Chrome、`npm run build && npx vite preview --port 5199` のビルド済み配信、size 64)で遊んだ記録。
操作は Chrome DevTools 経由でチップ(胞子苔・疫病)と島のクリックを実際の UI イベント(canvas の click)として送り、100 倍速で石板の警告と HUD を読んだ
(M10R-08 と同じ方法。集落 = セル (15, 32)、北の谷 = セル (22, 21)。画面座標はセル欄から対応表を作って決めた)。
放流は UI の環 1・0.5(力 4)、疫病は UI の環 4(力 24)。石板の警告「狼の群れが北の谷に下りた」を見てから谷を叩く(人が気づいて動く形)。

## 作り直しの前に分かったこと(記録)

- 最初の設計(集落に狼 環 6 を落とし、集落へ疫病 環 6)は通し実行では通ったが、UI では **波と同じ tick に打たないと効かない**
  (狼の拡散 0.2/tick で 10 tick 後には環 6 の外へ出る)。手動 1 回目は 14 年目の波を 400 ms 遅れで叩いて祈りが出た。→ 波を谷に落とす形へ(LD §8.10)。
- 石板の年表に台詞が二重に出た(「94 年: 狼の群れが…」と「94 年: ⚠ 狼の群れが…」)。→ 警告の年表行を重ねないよう修正。

## チェックリスト

- [x] 予言に「八年ごとに北の谷へ狼の群れ」「谷を疫病で病ませれば、民は祈らずに済む」「叶わなかった祈りは、取り下げても民の記憶に刻まれ」が読める
- [x] 波の年に警告「⚠ 狼の群れが北の谷に下りた。集落へ着くまで三月」が出て、年表にも同じ台詞が残る
- [x] 春の 8〜9 日目に谷を叩けば祈りが出ない。見送った波は 2 年後に「祈り: 狼を減らして」が出て、取り下げの年に HUD の上限が −0.1
- [x] 力が 24 に満たない波は見送るしかない(年収 12 は実効 ≈ 3/年)
- [x] 100 年目に「島は生き延びた / 祈りに一度も応えなかった」

## 1 回目: 苔を 3 年ごとに集落へ、警告を見たら力 24 があれば谷に疫病 — 島は生き延びた

| 年 | 力 | HUD | 石板・操作 |
|---|---|---|---|
| 1〜4 | 42 → 47 | 歌(3) · 信仰 0.49 · 上限 1.00 | 3 年ごとに集落へ苔(儀式) |
| 6 | 49 → 25 | 信仰 0.47 | ⚠「狼の群れが北の谷に下りた。集落へ着くまで三月」。春 9 日目に谷へ疫病。祈りは出ない。谷は支え半径の外なので信仰は減らない |
| 14 / 22 | 37 → 13 / 28 → 4 | 信仰 0.77 → 1.00 | 同じく谷へ疫病。祈りは出ない |
| 30 | 16 | 上限 1.00 | 力が足りず見送り。32 年目に祈り「狼を減らして」、34 年目に取り下げ → **上限 0.90** |
| 38 / 54 / 70 / 86 / 94 | 28 → 4 など | 上限 0.90 → 0.60 | 力があれば谷へ。46 / 62 / 78 は見送り(それぞれ取り下げで上限 −0.1) |
| 100 | 9 | 歌(3) · 信仰 0.60 / 上限 0.60 | **島は生き延びた / 文明の段階 3(歌) / 祈りに一度も応えなかった**。介入 40 回 · 使った力 320。先回り 8 回、見送り 4 回 |

- 見えた点: 警告を見て春のうちに谷を叩けば祈りが出ない。見送るたびに上限が 0.1 減るのが HUD で読め、「あと何回見送れるか」を数えられる。
  力は儀式(4 / 3 年)と先回り(24 / 8 年)でほぼ使い切り、欲張っても 12 波中 8 回が上限。
- 分かりにくかった点: 狼が谷から集落へ歩く様子は狼レイヤーを開かないと見えない。警告の文言(三月)で足りるが、狼レイヤーへ切り替える案内があってもよい(記録)。

## 判断(2026-09-23)

想定解が UI で再現でき、見送りの記憶が HUD で読める。M10R-07 は main へ。
