# 計測の台(6 画の内訳と fps)

## What to build

観察画面の試作ページを Playwright で開き、寄せ先の 6 画(集落・船台・群れ・林・狼・海岸、空の舟 25 年目、朝、時間を止める)を回って `__observeStats`(三角形・draw call・fps)と `__observeBreakdown()`(区分ごとの内訳)を JSON に書く。軽量化の各チケットの前後の比較に使う。

別の worktree で進め、終わったら feat/m21 へ取り込む(ユーザーの指示「一連の軽量化は worktree を分けて実施」)。

## 作業ログ

### 2026-09-24

- 台を作った(c81aee5)。使い方は `tools/bench-observe.ts` の先頭。
  - `npm run bench:observe` で 6 画を回り、`.bench/observe-<日時>.json`(`.gitignore` 済み)に書く。`--out` で置き場所、`--url` で動いている Vite を使う(無ければ自分で 5331 番から空きを探して立てる)。1 回 40〜50 秒。
  - `npm run bench:observe:compare -- 前.json 後.json` で、画ごとの三角形・draw call・fps と、区分ごとの drawn / inView / shadow の前 → 後を Markdown の表に出す。JSON を 1 つだけ渡すと要約の表。
- 三角形と draw call を揃えるための工夫: 時刻と本体を止めても(`freeze=1`)観察の層の動物は実時間で歩き、近い個体の骨入り・木の段・群れと狼の寄せ先の狙いが変わるので、実時間のままでは画ごとに数千〜数万三角形揺れた(同じ 2 回で 狼 1,096 千 と 1,127 千)。
  Playwright の `page.clock` でも、ページごとに `performance.now` の起点が数 ms ずれて最初のコマの dt が変わり、個体の状態が分かれて揃わなかった。
  台がページの `performance.now` と `requestAnimationFrame` を差し替え、1 コマ 1/60 s で決まったコマ数だけ進めるようにして揃った。fps だけは開き直して実時間で測る。
- 走りの一致: 同じ条件で 5 回(動いている Vite を使った 1 回、自分で立てた 4 回)走らせ、6 画の三角形・draw call・区分ごとの内訳が全部一致した(測りの間の 4 回の読みも含めて)。
  群れと狼は、測りの間にも動物が歩いて 0.5 s ごとの値が変わる(群れ 1,193.7 → 1,203.2 千)が、それも毎回同じ並びになる。
- fps の注意: headless の rAF は 60 で頭打ちなので、既定で垂直同期とコマの上限を外している(`--vsync` で戻す。戻すと 60 に張り付き、別の作業が GPU を使っている間は 50〜53 に落ちた)。
  同じ GPU(Apple M4)で別の作業の観察画面が動いていると大きく揺れる。前後を比べるときは続けて測り、数 fps の差は揺れの範囲として読む。
- 基準(軽量化の前、86ce1b9 の描画、1280×720 @1x、Chromium 153 headless 上限なし、GPU: ANGLE Metal Apple M4)。三角形は本の描画と影の描画の合計、単位は千三角形。fps は 2 回の走りの平均と、読みの幅:

| 画 | 三角形 | draw call | fps | 本の描画 drawn / inView | 影 | 草 drawn / inView | 鐘樹 drawn / inView |
|---|---|---|---|---|---|---|---|
| 集落 | 1,397.2 | 102 | 75(74〜76) | 1,118 / 383 | 337 | 512 / 105 | 259 / 63 |
| 船台 | 1,083.4 | 103 | 76(75〜77) | 897 / 397 | 237 | 392 / 120 | 161 / 55 |
| 群れ | 1,203.2 | 92 | 77(74〜81) | 1,013 / 236 | 242 | 502 / 41 | 164 / 0 |
| 林 | 1,094.6 | 104 | 75(73〜78) | 920 / 618 | 224 | 428 / 206 | 146 / 143 |
| 狼 | 1,134.4 | 112 | 73(70〜78) | 943 / 551 | 223 | 452 / 173 | 146 / 110 |
| 海岸 | 1,276.0 | 87 | 77(75〜81) | 1,076 / 272 | 271 | 537 / 49 | 192 / 33 |

集落の画は設計書の試算(1,397 千、draw call 102)と同じ。群れ・狼は設計書の試算の時点と寄せ先の狙い(その時の群れの重心)が違うので値が違う。台では狙いも毎回同じになる。
