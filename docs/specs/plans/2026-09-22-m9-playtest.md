# M9 手動受入プレイテスト: 「祈りに応えるな」「霊脈枯れ」

2026-09-22。ブラウザ(Chrome、`npm run build && npx vite preview --port 5199` のビルド済み配信、size 64)で 3 回遊んだ記録。
操作は Chrome DevTools 経由でチップ(苔・疫病・勅令)と島のクリックを実際の UI イベントとして送り、100 倍速で年ごとに石板と HUD を読んだ。
集落のクリック位置は、島を細かく叩いてセル欄の座標(祈りに応えるな = (35, 43)、霊脈枯れ = (42, 27))を確かめて決めた。

## チェックリスト

- [x] 予言・節目・力の残量が最初から石板に見える
- [x] HUD に信仰が見え、儀式(3 年ごとの同じ放流)で上がるのが分かる(0.50 → 0.60 → … → 1.00)
- [x] 祈りが石板に「祈り: 狼を減らして(残り N 年)」で出て、応えれば消え、困りごとが消えれば「民は祈るのをやめた」が年表に並ぶ
- [x] 勅令の行(「採掘を止めよ / 再開せよ」)が見え、従えば HUD に「採掘 止」、年表に「民は採掘を止めた」
- [x] 少なくとも 1 回は負け、理由が石板の文言で分かる(1 回目: 「祈りに 1 回応えた」)

## 1 回目: 祈りに応えるな — 祈りが出たら応える(集落に疫病) — 島は滅びた

| 年 | 力 | HUD | 石板・操作 |
|---|---|---|---|
| 0 | 40 / 120 | 歌(3) · 民 0 · 信仰 0.50 | 予言と節目 3 つ(6 / 18 / 90 年目) |
| 5 | 54 | 民 753 · 信仰 0.48 | 減衰でゆっくり下がる |
| 10 | 69 → 45 | 民 354 · 信仰 0.45 | 「祈り: 狼を減らして(残り 5 年)」。疫病(24)を集落へ |
| 11 | 48 | 信仰 0.60 | 年表: 「信仰が 0.45 → 0.60 に上がった」「祈りに応えた: 狼を減らして」「島は滅びた」 |

結果: **島は滅びた / 祈りに 1 回応えた**。応えた瞬間に信仰は上がるが、翌年の判定で滅びる。理由は予言(「一度でも応えれば、民は考えるのをやめ」)と判定の文言で分かる。

## 2 回目: 祈りに応えるな — 儀式(3 年ごとに集落へ苔) — 島は生き延びた

| 年 | 力 | HUD | 石板・操作 |
|---|---|---|---|
| 1〜 | 40 → | 信仰 0.50 → 0.47 | 1・4・7 年目に苔。3 回そろうまで(7 年目)は減衰だけ |
| 10 | 57 | 信仰 0.60 | 「祈り: 狼を減らして」。応えない |
| 13 | 61 | 信仰 0.73 | 年表: 「困りごとが消え、民は祈るのをやめた: 狼を減らして」(狼が減って取り下げ) |
| 20 | 71 | 信仰 1.00 | 以後、祈り(12 年ごと)はすべて取り下げになり信仰は 1.00 のまま |
| 72 | 120 | — | ⚠ 力が上限(120)に達している(儀式は 4 / 3 年 なので力が余る) |
| 100 | 120 | 歌(3) · 民 481 · 信仰 1.00 | **島は生き延びた / 文明の段階 3(歌) / 祈りに一度も応えなかった** |

- 見えた点: 儀式が効き始める(3 回目)までの 7 年が最も細い(0.47)。最初の狼(6 年目)の祈りは 10 年目に出て、13 年目に取り下げ。祈り 11 回はすべて取り下げになった。
- 悩む余地: 20 年目以降は信仰 1.00 で力も余り、緊張が無い。校正の候補(記録に残す): 狼の群れを大きくして祈りが期限まで残るようにする、儀式の値段、または後半に別の困りごと(草)を入れる。

## 3 回目: 霊脈枯れ — 儀式で信仰を積み、0.6 で「採掘を止めよ」 — 島は生き延びた

| 年 | 力 | HUD | 石板・操作 |
|---|---|---|---|
| 0 | 40 | 石(4) · 進み 1% · 信仰 0.50 | 予言と節目(6 / 30 / 90 年目) |
| 8 | — | 帆(5) | 年表: 「文明が 石 → 帆 に上がった」(掘り続けている) |
| 10 | 57 | 帆(5) · 燃料 567 / 4年 · 信仰 **0.60** | HUD が 0.60 と出たので「採掘を止めよ」 |
| 11 | 55 | 信仰 0.64 | 年表: **「民は聞かなかった(信仰 0.60 < 0.6)」** ← 実値 0.597 の四捨五入。読めない |
| 12 | — | 信仰 0.73 · 採掘 止 | 年表: 「民は採掘を止めた」。「困りごとが消え、民は祈るのをやめた」 |
| 20〜 | 69 → 120 | 帆(5) · 進み 46%(止まったまま) · 信仰 1.00 · 採掘 止 | 祈りは取り下げが続く |
| 100 | 120 | 帆(5) · 民 312 · 燃料 207 / 4年 · 信仰 1.00 · 採掘 止 | **島は生き延びた / 文明の段階 5(帆) / 集落の生気 92%** |

- 分かりにくかった点: **信仰の表示が四捨五入**で、0.597 が「0.60」と出て勅令が通らず、年表の「信仰 0.60 < 0.6」が読めない。→ 修正: 信仰の表示を小数 2 桁の切り捨て(`formatFaith`)に統一(HUD・年表・判定・警告)。「民は聞かなかった(信仰 0.59。0.6 に足りない)」。単体テスト `tests/unit/faith.test.ts`、`tests/unit/ui.tablet.test.ts`。
- 分かりにくかった点: **集落の生気が HUD で読めない**(判定条件なのに、生気レイヤーを見るしかない)。→ 修正: 文明の行に「· 生気 NN%」(集落の支え半径の平均、`CivState.vitality`)、5 割を切ったら警告「集落の生気が痩せている(NN%。霊脈が細ると苔を放っても戻らない)」。単体テスト `tests/unit/ui.hud.test.ts`、`tests/unit/scenario.warnings.test.ts`、`tests/unit/world.civilization.edict.test.ts`。
- 見えた点: 12 年目に止めたので脈はほぼ無傷(生気 92%)。石板の節目「30 年目: 脈は七割」より前に止められた。止めた後は段階が帆で止まり、燃料の蓄えが減るだけ(100 年で 207 残る)。

## まとめ

- 直した表示: 信仰の切り捨て表示、HUD の集落の生気と警告。
