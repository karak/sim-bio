# 狼レイヤーを見ている間に来た狼の波の台詞を、石板に出すかどうか

優先度: Could (ゲーム設計の判断待ち。不具合ではない)

## 経緯

PR #4 (M21-02 D5、2026-09-30 マージ) のマージ後レビュー (2026-10-11) で気になった点の申し送り。レビューでは、直すべき不具合は見つかっていない。

## 今の挙動

- 予定の告知は、その種のレイヤーを見ている間に発火すると、石板に出ない (`src/scenario/ScenarioRunner.ts` の `fireDue`、「その種のレイヤーを見ている間の告知は最初から出さない」)。
- この扱いは PR #4 で意図して入れたもの。チップを押す必要が無いので告知を出さない、という考え方。
- ただし、告知はチップだけではなく、台詞そのものを運んでいる。`ScheduledCommand` の型の説明 (`src/scenario/types.ts`) では、「星が気づいて動く猶予を知らせる舞台装置の台詞」としている。
- 抑止された時、台詞を読める場所は年表だけになる。`everyYears` のある text 付きの予定は、年表に text を積み (`fireDue`)、石板の年表はそれをそのまま出す (`src/scenario/describe.ts` の `case 'scheduled'`)。

## 影響範囲 (main 300a8e4 の `assets/data/scenarios.json`)

| シナリオ | 予定 | 影響 |
|---|---|---|
| `no-answer` | 6 年目から 8 年ごとに wolf、`noticeYears: 2`、「狼の群れが北の谷に下りた。集落へ着くまで三月」 | 狼レイヤーを見ているプレイヤーには、「着くまで三月」という猶予の台詞が石板に出ない。年表には残る |
| `test-event` (hidden) | 1 年目に wolf、`everyYears` なし | e2e 用。狼レイヤーを見ずに始めるので、影響しない |

単発 (`everyYears` なし) の text 付きの予定は、年表に text を積まない。そのため、今後この形で種の告知を足すと、見ている間に発火した台詞はどこにも残らない。

## 決めてほしいこと

- A. 今のまま (見ている間は出さない。台詞は年表で読める)
  - 影響: コードは変えない。単発の予定に種の告知を足す時は、上の「どこにも残らない」形になることに注意が要る。
- B. 見ている間も台詞は石板に出し、チップだけを出さない
  - 影響: `Warning` からチップを外す経路が要る (今のチップは `id` の有無で決まる)。runner のテスト (「見ている間に発火した告知は最初から出さない」) の期待値が変わる。
- C. 見ている間に発火した告知は、既読扱いで 1 年だけ出す
  - 影響: 抑止の分岐を寿命 1 年の登録に変える。B と同じく、runner のテストの期待値が変わる。

## Acceptance criteria

- [ ] A / B / C (または別の案) のどれにするかを、ユーザーが決める
- [ ] B か C を選んだ場合: 実装の前に、runner のテストを新しい挙動で赤にしてから直す
- [ ] A を選んだ場合: 単発の予定でも text を年表に積むかどうかを、別に決める (積まないなら、その理由を `fireDue` のコメントに残す)
