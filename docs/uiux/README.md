# docs/uiux

画面の流れと配置 (UX の設計) を置くフォルダ。見た目の意匠 (色・絵・ロゴ) は docs/design に置き、ここには置かない。

## 中身

| 物 | 中身 |
|---|---|
| `2026-10-04-title-flow.md` | タイトル画面まわりの画面遷移図 (Mermaid の stateDiagram)・画面ごとの目的と入口と出口と戻り道・URL で直に開く場合の起動の判断・UX の根拠・決めること (M24-00) |
| `wireframes/*.svg` | 画面ごとの W/F。`<画面>-desktop.svg` (1280×720) と `<画面>-narrow.svg` (幅 390、高さ 844) の 2 つの幅 |
| `wireframes/make_wireframes.py` | W/F を書き出す台本。`python3 docs/uiux/wireframes/make_wireframes.py` で全部を書き直す。SVG を手で直さず、台本を直して書き直す |

W/F の画面:

| 名 | 画面 |
|---|---|
| `title` | タイトル (ロゴ・背景のデモ・メニュー) |
| `new-game` | 新規ゲーム (自由モード / 石板を選ぶ) |
| `load` | ロード (枠・ファイル。狭い画面には確かめの板も) |
| `config` | コンフィグ |
| `harbor` | 港の板 (タイトルから。狭い画面には空のときの見せ方も) |
| `stage` | 操作画面の「タイトルへ」の札と確かめ |

## 図の読み方

- 遷移図の箱は画面、矢印は押す操作。矢印の字は「押すもの (条件)」
- 「起動の判断」は画面ではなく、起動したときにどこへ行くかを決める所 (純粋な関数 `bootRouteOf`、src/app/place.ts。M24-01)
- 「操作画面」「判定の板」「訪問」「観察画面」はいまの作り。新しいのはタイトルとその下の 4 つの板と、各舞台の「タイトルへ」

## W/F の読み方

- ロー・フィデリティ。色は灰の濃淡だけで、濃さは強さ (いちばん濃い塗りが既定の選択、白地が普通の札、破線の灰地が空の枠)
- ×の付いた灰の四角は絵の置き場 (背景のデモ・ロゴ・石板の絵)。意匠は決めない
- 破線の白い吹き出しは注。画面には出ない
- 字は文の例。正の文は実装の票 (M24-01〜03) で決める。いまの作りにある文 (確かめの板・港の板の見出しと札・結末の文の形・閉港の文など) は、その文を写した。島の名・碑文・年・日時は例
- 板の後ろの暗い灰は、タイトルの背景を暗くしたもの
