# 観察区域の地形・海岸・植生

## What to build

区域(半径 8)の高解像度の地面(セルの標高を補間 + 起伏)、地面の質感(草地・土・岩・砂・浅瀬)、海と沈む海岸、草・月草・苔・森の木・鐘樹を密度から配置する。区域外は遠景。
