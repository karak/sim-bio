# デフォルメ試作(Switch 世代の密度のモデルと組み立て一式)

## What to build

基準画の絵を、ブラウザで動く小規模ポリゴン(Nintendo Switch 初代世代の 3D ポケモン程度)にデフォルメしたモデルで試作し、観察区域の一角を組み立てて動かす。対象は月鹿 1 頭(リグと 待機・歩く・食む・倒れる)、鐘樹 1 本(芽・成木・株)、集落の一角(小屋・灯り・船台)、地面と草。陰影(トゥーン寄りのランプ・縁の光・色調補正)で基準画の塗りに寄せる。3D 化の作り方(AI の 3D 生成 / tools/blender の部品集)を月鹿で比べて決める。

## Acceptance criteria

- [x] 月鹿・鐘樹・集落の一角・地面がブラウザ(Three.js)で組み上がり、区域の一角として見られる(observe.html、13bc446 fd2b309 359a104)
- [x] 基準画とゲーム内の比較画を並べた(docs/design/qa/observe/deer-compare.png・proto-*.png、ボード https://claude.ai/artifact/RHJkbfdvm7Y2SFe6Pwh794)。差は deer.md・environment.md とボードに記録
- [x] 鹿 300 頭 + 鐘樹 140 本 + 草 25,000 で 75fps(画面の上限)。draw call は既定の密度で 167(予算内)、三角形は 1.73 M で予算を 15% 超え(M22-03 で草の LOD と水面の 2 段化)
- [ ] 3D 化の作り方: Blender の部品集(案 A)で全部作れた(鹿 36 分・環境 20 分、外部費用 0、ライセンス問題なし)。AI の 3D 生成(案 B)はキーが無く未比較。**ユーザーの判断待ち**
- [ ] ユーザーの承認を得る(試作の見た目と作り方)
