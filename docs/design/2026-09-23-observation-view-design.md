# 観察画面(空の舟)の設計 — M22-00

方向性の決定(質疑 12 問・ボードへの判断・申し送り)は `docs/design/2026-09-23-observation-view.md`、絵の物差しは `assets/textures/board/`。
この文書は、それを実装できる形(区域・データの形・時間・カメラ・場面の引き金・アセットと予算・描画の構成・検証)に落とす。

## 1. 区域(本体の実測、2026-09-23)

空の舟(seed 42、size 64)を想定解(毎年 1 本、20 年目に着工)で回して、集落 2787 = (35, 43) の半径 8 を測った。

| 年 | 陸 / 197 セル | 標高(最小/最大) | 区域の密度の合計(鹿 / 兎 / 狼 / 鐘樹 / 草 / 苔) | 舟 |
|---|---|---|---|---|
| 0 | 185 | 0.246 / 0.514 | 3.7 / 3.7 / 1.9 / 0 / 55.5 / 9.3 | — |
| 1 | 185 | — | 5.6 / 1.8 / 4.5 / 21.0 / 27.1 / 167.7 | 民の林が立つ(環 4) |
| 20 | 178 | 0.235 / 0.503 | 4.8 / 1.9 / 1.7 / 59.1 / 16.4 / 129.2 | 着工 |
| 40 | 166 | 0.223 / 0.491 | 2.6 / 3.3 / 1.6 / 51.1 / 16.1 / 116.1 | 飛び立ち(escaped) |

- **海岸は区域の中にある**(南の縁と北の池)。沈降は区域の中で見える(40 年で陸が 185 → 166)。「滅びの兆しと終わり」は区域の中で撮れる。
- 起伏は小さい(標高差 0.27 = 本体の heightScale 12 で 3.2 単位)。観察画面では縦を強調する(§5)。
- 炎蜥蜴は区域に出ない(密度 0)。アセットは作らない。

世界の尺度: **1 セル = 10 m**(区域の直径 170 m)、鹿の体高 1.4 m。標高は `(e − SEA_LEVEL) × 60 m` を基準に、区域の見栄えで係数を決める。

## 2. 描画の構成

- 新しいモジュール `src/observe/`。**本体と SceneView には手を入れない**(本体は読むだけ、バランスと通し実行は変わらない)。
- 観察画面は **別の canvas と別の WebGLRenderer** を持ち、入ったときに作って戻ると破棄する(操作画面の SceneView と同時に描かない)。
- `ObservationView` の入力は毎フレーム `(snapshot, timeline, realDt)`。出力は描画だけ。
  - `snapshot`: 区域の密度・標高・生気・舟・文明・季節(`dayOfYear`)
  - `timeline`: 介入(`intervene` の command)、予定の出来事、段階の変化、判定
- 純粋な部分(区域の切り出し、頭数の目標、個体の状態機械、場面の引き金、カメラのショット選び)は Three.js から切り離し、単体テストする。

```
src/observe/
  area.ts          区域の切り出しと高解像度の地形 (純粋)
  population.ts    密度 → 種ごと・セルごとの目標頭数 (純粋)
  agents.ts        個体の状態機械と群れ・狩り・民の行動 (純粋、決定論の RNG)
  scenes.ts        場面の引き金 (舟の段階、飛び立ち、介入の演出、滅び) (純粋)
  director.ts      自動カメラのショット選び (純粋)
  ObservationView.ts  Three.js の組み立て (地形・植生・個体・集落・舟・演出・後処理)
  assets.ts        GLB の読み込みと LOD
```

## 3. 個体層(データの形)

```ts
type Agent = {
  id: number;
  species: 'deer' | 'wolf' | 'rabbit';
  role: 'wild' | 'folk';           // folk = 知性ある月鹿 (civ.speciesId の種、集落の支え半径の中)
  x: number; z: number; heading: number;  // m、区域の中心が原点
  state: AgentState;
  t: number;                       // 今の状態に入ってからの実時間 (秒)
  target?: { x: number; z: number } | { agent: number };
};
type AgentState =
  | 'idle' | 'walk' | 'graze' | 'flee' | 'stalk' | 'chase'   // 野生
  | 'carry' | 'gather' | 'board'                            // 民 (材を運ぶ、舟・灯りに集う、乗り込む)
  | 'enter' | 'leave' | 'fall' | 'return';                  // 出入りと死 (倒れる → 生気の光になって還る)
```

- **頭数は密度に忠実**: `target[species][cell] = round(density × K[species])`。K は 鹿 10、兎 10、狼 8(区域でそれぞれ 30〜60 / 20〜35 / 12〜35 頭)。
  鐘樹・森・草は個体でなく植生として 1 セルに `density × 3` 本(鐘樹で最大 ~180 本)。
- **増減は演出で合わせる**: 目標より少なければ `enter`(区域の縁から歩いて入る)か、同じ種の近くに生まれる。多ければ `leave`(縁から出る)か `fall`(倒れて還る)。
  1 秒あたりの出入りに上限を置き、暦を 10x にしても個体は早送りせず入れ替わりを溶かす(決定 3)。
- **狩りは狼と鹿が重なるセルでだけ**: 鹿を減らす必要があり、同じセル(または隣)に狼がいるとき、減らす 1 頭を `stalk → chase → fall` で狼に倒させる。それ以外の減少は静かに `leave`。
- **倒れた個体は生気に還る**: `fall`(8 秒横たわる)→ `return`(淡いシアン寄りの光の粒になって土に沈む、6 秒)。血は描かない(決定 7)。
- **民の行動**: `role = folk` は集落の支え半径 8 の中の月鹿。舟の建造中(`ship && !launchedYear && civ.stage ≥ 帆`)は一部が `carry`(鐘樹の林から船台へ材を曳く)、
  夜は灯りに `gather`、飛び立ちでは船台に `gather → board`。
- 決定論: 種(seed)と tick から RNG を作り、同じ snapshot の列なら同じ動き(テストで固定する)。

## 4. 時間

- 個体・昼夜・風・水面は **実時間**。昼夜 1 周 = 6 分。季節(色調・草の色)は `dayOfYear` から。
- 観察画面の速度は ⏸ / 1x / 10x(100x は観察画面では選べない。入るときに 10x に落とす)。
- 本体の値(密度・標高・舟の進み)は tick ごとに変わるが、観察画面は **見た目の値を実時間でなめらかに追わせる**(海面・植生の密度・舟の段階の切り替えは数秒かけて移る)。

## 5. 地形・植生

- 区域の地面: セルの標高を 1 セル 6 分割の格子(102×102)に双三次補間し、小さな起伏(決定論のノイズ)を足す。縦は §1 の係数 × 1.6 で強調。
- 質感: 草地・土・岩・砂・浅瀬をセルの値(植生・標高・海までの距離)で混ぜる。色味は `sheets/terrain.png`、質感は CC0(Poly Haven / ambientCG)。
- 海: 区域の南と北の池。波打ち際の泡と浅瀬の色。沈降で海岸線が動く(標高が下がる)。
- 植生: 草の房と月草は GPU インスタンス(区域で最大 2 万房、風で揺れる)。苔は地面の色と、湿った石の上の房。鐘樹は 芽 / 若木 / 成木 / 株 の 4 段を密度と伐採で選ぶ。
- 区域の外: 本体の 64×64 の地形を低解像度で置き、霧で溶かす(遠景)。

## 6. 場面の引き金(本体を変えずに読める)

| 場面 | 引き金 | 見せ方 |
|---|---|---|
| 舟が育つ | `ship.progress`(0〜120)| 段階: 竜骨 0〜24、肋 24〜48、板 48〜72、帆柱 72〜96、帆 96〜120。民が `carry` で材を運ぶ。伐った鐘樹は株になる(`belltree` 密度が下がったセル) |
| 飛び立ち | `ship.launchedYear` が付いた | 民が船台に集う(20 秒)→ 乗り込む → 舟が浮いて水平線へ(30 秒)→ 空の集落(灯りが一つずつ消える)。判定 escaped の後も観察画面はこの場面を最後まで流す |
| 種を放ったあと | `timeline` の `intervene`(spawn_species / disaster / set_climate)で区域の中のもの | 植えた場所に芽吹きの光、疫病は紫灰の霧が区域を漂う、雨は雨の粒と水たまり。区域の外の介入は遠景に小さく |
| 帆を失う | `civ.stage` が帆(5)を下回った、または `ship` があって `sim.ship.halted` の年 | 灯りが消え、船台の民が散る。工事の音の代わりに、材の山がそのまま残る |
| 沈む | 区域の陸セル数の減少、`land_low` 相当 | 海岸線が動き、波が林の縁を洗う。沈んだ鐘樹は立ち枯れの幹が水から出る |
| 終わり(dead) | 判定 dead | 区域が水に沈むか(沈没)、灯りが消えた集落に群れがいなくなる(文明の崩壊) |

## 7. カメラ

- 既定は **自動の自然記録調**。ショットの種類: 群れに寄る(低い位置、望遠寄り)、林を横移動、舟を見上げる、集落の俯瞰、狩りの追従、海岸の引き。
- ショットは 12〜20 秒。次のショットは「今いちばん見るべきもの」で選ぶ: 場面の引き金(§6)> 狩り > 民の行動 > 群れ > 風景。同じ種類は続けない。
- 操作(ドラッグ・ホイール)で自由カメラ。個体を押すとその個体を追う。20 秒触らないと自動に戻る。
- 高さの下限(地面 + 0.5 m)、区域の外に出ない。

## 8. アセットと予算(Switch 初代世代の 3D ポケモン程度)

| 対象 | 三角形(近 / 群れ) | テクスチャ | 動き | 基準画 |
|---|---|---|---|---|
| 月鹿(雄・雌・子、民は紐) | 3,000 / 900 | 512² + 発光マスク | 待機・歩く・走る・食む・倒れる | creatures/deer |
| 灰狼 | 2,500 / 800 | 512² + 発光マスク | 待機・歩く・忍ぶ・走る・倒す | creatures/wolf |
| 土兎 | 1,500 / 500 | 256² + 発光マスク | 待機・跳ぶ・食む・立つ | creatures/rabbit |
| 鐘樹(芽・若木・成木・株) | 成木 4,000 / 1,200 | 幹 512² + 葉のカード | 風・鐘の灯り | sheets/belltree |
| 草・月草の房 | 16〜40 / 房 | 1 枚のアトラス | 風 | sheets/flora |
| 集落の部品(小屋・灯り柱・石垣・衝立・船台) | 各 800〜2,000 | 石と木のアトラス 1024² | 灯りの明滅 | sheets/settlement |
| 舟(5 段階 + 完成) | 各 6,000 | 1024² | 浮上・帆 | sheets/ship |
| 演出(生気の粒・疫病の霧・芽吹き・雨・泡) | 粒子 | 小さなスプライト | — | sheets/effects |

- **画風は動物側が正**(申し送り)。植物・集落・舟の塗りは動物の基準画(丸めた角ばり、柔らかい陰影、シアンの発光)に寄せる。
- 陰影: トゥーン寄りのランプ(3 段 + なめらかな境界)、縁の光、シアンの発光マスクに bloom、最後に絵画調の色調補正(暖色のハイライト・寒色の影・わずかな紙の粒)。
- 描画の予算: 区域の三角形 150 万以下、draw call 200 以下、個体 400 以下で デスクトップ Chrome(M シリーズの Mac)60fps。
  群れの LOD は距離 30 m で切り替え。個体数が多いときは頂点アニメをテクスチャに焼いたインスタンス化に移る(M22-02 の計測で判断)。

## 9. アセットの作り方(M22-02 で決める)

- **A: tools/blender の部品集で起こす**(既存の鹿・兎・狼のローポリ工程を拡張)。外部サービス不要、今すぐ使える。四つ足のリグと 5 つのアニメも Blender のスクリプトで作る。
- **B: AI の 3D 生成**(Meshy / Tripo など)。基準画から形を起こせるが、API キーが無い(2026-09-23 時点)。使う場合は `.env` にキーを置き(コミットしない)、生成物のライセンスを確認する。
- 試作は A で進め、比較画で基準画に届かなければ B を提案する(キーの用意はユーザーの判断)。

## 10. 検証

- 単体: `population.ts`(密度 → 頭数、出入りの上限)、`agents.ts`(状態遷移、狩りは重なるセルだけ、倒れた個体は還る、決定論)、`scenes.ts`(舟の段階、飛び立ち・帆を失う・介入の引き金)、`director.ts`(優先順位、同じショットが続かない)。
- E2E: 空の舟で観察画面に入る・戻る・速度・個体を押して追う。
- 比較画: 基準画と同じ向き・同じ光でゲーム内を撮り、`docs/design/qa/` に並べる(M6〜M8 の生き物の検証と同じ流儀)。
- 性能: Chrome DevTools のトレースで 60fps と三角形・draw call を記録する。
- 本体に触れないことの確認: 単体 521・E2E・通し実行が変わらない。

## 12. 実装で決めたこと(M22-04、2026-09-23)

- **頭数の丸め**: 実測の密度は 1 セル 0.02 前後なので、セルごとの round では全部 0 になる。区域の合計を round(Σ密度 × K) にし、セルへは最大剰余法で配る。
- **民の範囲は集落から 3 セル**: 支え半径 8 のままだと区域の鹿が全部民になり、夜は全頭が灯りに寄り、飛び立ちで群れが消える。`folkRuleFor(civ, 3)`。
  25 年目の保存では集落の近くの鹿の密度が低く、民は 0 頭になる(観察セッション M22-09 で、民を「集落に近い順に N 頭」にするかを判断する)。
- **狩り以外の減少**: 30% は倒れて還る(死を見せる)、残りは縁から出ていく。
- **数え方**: 入ってくる個体は向かう先のセルで数え、狩られている鹿は数えず、乗り込んだ民は数える(飛び立ちの後に鹿を補わない)。
- **目印**: 船台 = 集落に最も近い海辺の陸セル、林 = 鐘樹の密度が最大のセル、灯り = 集落と 8 近傍、海岸 = 海に接する辺が最も多い陸セル。
- **狩りの打ち切り**: 追いが 15 秒続けば捕まえたことにする。カメラの割り込みは場面と狩りだけ、4 秒映した後。
- **帆を失う**: `sim.ship.halted` は snapshot に無いので、`civ.stage < 帆` だけで見る。
- **描画**: 月鹿はカメラに近い 24 頭を SkinnedMesh、残りを VAT の InstancedMesh。鐘樹の成木は 45 m で lod1 に切り替える。

## 11. 進め方

1. M22-02 デフォルメ試作: 月鹿 1 頭(リグ・待機・歩く・食む・倒れる)、鐘樹(芽・成木・株)、集落の一角(小屋・灯り・船台)、地面と草を区域の一角に組み、陰影と色調を入れる。比較画と 60fps(鹿 300 頭 + 鐘樹 200 本)。**ここで美観チェック(ユーザー)**。
2. M22-04 個体層は見た目に依存しないので、M22-02 と並行して純粋モジュールとテストを先に作る。
3. 美観チェックの後、M22-03(地形・植生)・M22-05(動物)・M22-06(集落と舟)・M22-07(演出)・M22-08(UI とカメラ)。最後に M22-09 観察セッション。
