# 舞台(島)デザインの案 — 外部知識からの抽出

調査(`science/`, `games/` 各ファイル)から、この島の舞台設計に使える考えをまとめる。
「振動を出す」と「見ていて分かる」の両方に効くものを優先した。

## A. 振動を生む舞台の条件(モデル側)

| 案 | 根拠 | 実装の当たり |
|---|---|---|
| 摂食応答を飽和型(Holling II)にする | Rosenzweig-MacArthur。線形応答では振動が減衰する | `SpeciesDef.handlingTime` を追加し `intake = a·F/(1 + a·h·F)` |
| 草の回復に時間遅れを入れる | NetLogo Wolf-Sheep は草の再生時間があるときだけ持続振動 | 「枯れ草」バッファ。食べられた分は N tick 後に容量へ戻る |
| 餌を豊かにする(K↑)と振動、豊かすぎると崩壊 | enrichment のパラドックス | 降水スライダーが実質 K を動かす。プレイヤーが「豊かにしすぎて崩壊」を体験できる |
| 捕食者の拡散 > 被食者の拡散 | Turing 不安定化の条件 | 既に狼 0.2 > 鹿 0.15。差を広げると斑点・波が出やすい |
| 捕食者間干渉で振幅を抑える | Beddington-DeAngelis | 振動が激しすぎる種に `interference` 係数 |

## B. 振動を「見せる」舞台の条件(地形側)

1. **モザイク状の生息地**: 湿潤な森、乾いた草原、高地の岩場をパッチ状に配置し、間に境界を作る。
   反応拡散の波はパッチの境界で反射・屈折して目に見える模様になる。
   今の地形ノイズは滑らかすぎるので、水分ノイズの周波数を上げるか、川・湖で分断する。
2. **避難地(refugia)**: 捕食者が入れない小さな領域(狼の適合度が低い高地や湿地)を作ると、
   被食者がそこで生き残り、谷底での絶滅を防ぐ。振動が持続しやすくなる。
3. **回廊と隘路(corridor / bottleneck)**: 島を 2〜3 の「亜大陸」に分け、細い地峡でつなぐ。
   波が地峡を通って隣に伝わるのが見え、地峡を災害で切ると「隔離」が起きる。
4. **水場を離散的に置く**(Sebastian Lague): 湖や川の周りに動物が集まり、生活感が出る。密度モデルでも「水からの距離」を適合度に入れれば同じ効果。
5. **緯度・標高の勾配を強めに**: 北の寒冷地、南の温暖地、山頂の雪。気候スライダーを動かすと帯が上下に動くのが分かる。

## C. 可視化の舞台(UI 側)

- **合計グラフだけでは波が消える**(空間で位相がずれて相殺)。地域別(北・南・高地)またはクリックしたセルの時系列を出す。
- **介入マーカー付きグラフ**は本作の独自性。ブラウザ系の先行作はどれも「いじって眺める」止まり。
- **適合度 f を色で見せる**(Equilinox の満足度に相当)。「なぜここで鹿が減るか」が読める。
- **層ごとのパネル**(SimEarth)。今のレイヤー切替を「気候 / 植生 / 動物 / 介入履歴」の 4 パネルに整理する余地。

## D. シナリオの舞台(将来)

- Terra Nil 型: 地域ごとに「効くパラメータ」が違う舞台(乾燥島、寒冷島、火山島)。
- Niche 型: 島を渡る。1 つの島で得た種を次の島に持ち込む。
- SimEarth 型: 目標付きシナリオを勝敗なしの本体に後から被せる。
