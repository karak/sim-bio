# 観察画面の設計(区域・個体層・カメラ・場面・アセット一覧・性能予算)

## What to build

決定事項(質疑 12 問とボードへの判断)を実装できる設計書にする。区域(集落 2787 を中心に半径 8)と遠景、個体層のデータの形(密度 → 個体の出入り、行動の状態機械、狩りと生気に還る)、実時間と暦の切り分け、自動カメラのショット、4 つの場面の引き金(舟の進み・launchedYear・帆を失う・沈降・介入のログ)、アセット一覧と三角形・テクスチャの予算、描画の構成(シーンの切替、LOD、インスタンス化)。

## Blocked by

None (can start immediately)

## Acceptance criteria

- [ ] 区域と遠景、海岸が半径 8 に入るかを本体のスナップショットで確かめて記す
- [ ] 個体層のデータの形と状態機械を型で書き、密度との対応(頭数・出入り・狩りが起きる条件)を表にする
- [ ] 場面ごとに引き金となる本体の値・ログを列挙する(本体を変えずに読めるか、足すなら何を足すか)
- [ ] アセット一覧(動物・植物・集落・舟・地面・演出)と、Switch 世代の 3D ポケモン程度の三角形とテクスチャの予算、LOD の段
- [ ] ユーザーの承認を得て承認日時を記す
