# LLM が 3 票とも no と言った 3 手順の真偽を確かめ、本物なら直す

優先度: Should

## What to build

M25-06 の試しで `pnpm run judge` が 3 票とも no にした手順が 3 つある。製品の欠陥か、正本の文の言い方か、片付ける。

- HBR-006/6 (画 5): 「この石板で最後に判定の出た島」の下に島が出ていない
- CNF-002/2: 「やめる」が強調されて見えない
- SEL-003/3: 帯が「薄い琥珀」でなく細い黄色の線に見える

やること:
1. 画 (tests/e2e/baselines/ と `pnpm run shots` の出力) と製品のコードを見て、手順の文が言う状態が本当に出ているかを確かめる
2. 製品の欠陥なら、落ちる試験を先に書いて直す (基準画が変わるなら `pnpm run shots:update` で回を出し、承認はユーザー待ち)
3. 文の言い方の問題なら、**正本の行は変えない**。書き換えの案 (行・原文・案・理由) を報告に挙げる
4. judge の実行は手順ごとに 1 回まで (費用)。`claude -p` が使えなければ画を目で見て判じ、そう書く

- [ ] 文と判じたものは書き換えの案が報告にある (正本は変えていない)
