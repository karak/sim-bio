# 観察画面(空の舟)— 方向性の決定(2026-09-23、ユーザーとの質疑)

シミュレーションの可視化ではなく、見ていて楽しい 3D の観察画面を 1 シナリオ(空の舟)に入れる大型案件。
バランス調整とエンジニアリングのタスク(M21 の残り、M11 以降)より優先する。サウンドと BGM は対象外。
このあと、設計書(区域・個体層・カメラ・場面・アセット一覧・性能予算)とチケットを起こす。

## 決定事項

| # | 問い | 決定 |
|---|---|---|
| 0a | 対象シナリオ | **空の舟**(集落 = 帆の月鹿、鐘樹の民の林、舟の建造と飛び立ち、沈む島) |
| 0b | 個体の出どころ | **密度から作る見た目の層**。シミュレーションは今の密度のまま。バランスと通し実行に影響しない |
| 0c | 入り方 | **集落の周りに固定**(場所は選ばない) |
| 0d | アセットの見た目 | **高精細**(既存のローポリ鹿・兎・狼は作り直し) |
| 1 | 体験の芯 | **守った命の手触り**。箱庭を覗き込み、守った群れ・林・民が「生きている」と感じる。静かな生活の描写が主で、事件は時々 |
| 2 | 操作 | **見るだけ、時は流れる**。介入は操作画面だけ。観察画面は速度(⏸/1x/10x)とカメラ。警告・祈りは控えめな帯で知らせ、一押しで操作画面に戻れる。UI は極力消す |
| 3 | 時間 | **見た目は実時間、暦は別**。個体の動きと昼夜は実時間(昼夜 1 周は数分)。季節・密度・舟の進み・海面はシミュレーションから。10x でも個体は早送りせず、群れの入れ替わりを溶かす |
| 4 | カメラ | **自動の自然記録調 + 触れば自由**。既定はショットを巡る(群れに寄る、林を横移動、舟を見上げる、狼の狩りに切り替え)。操作すると自由カメラ、個体を押すと追う、放っておくと自動に戻る |
| 5 | トーン | **絵画的な写実**。形と質感は写実寄り、色と光は絵画のように整える(アニメ映画の背景美術のような) |
| 6 | 民の姿 | **鹿のまま、行動と痕跡で知性**。民は四つ足の月鹿(角に紐や飾り程度)。集落はムーの巨石遺構に手を入れたもの(積み直した石、蔓と樹皮の覆い、灯り)。材を運ぶ・舟の周りに集う・夜は灯りに寄るなど、野生の鹿と違う行動 |
| 7 | 死の描写 | **見せるが静かに、後は生気に**。追う → 倒す → 群れが散るまでは引きの画、血は描かない。倒れた個体はしばらく残り、淡い光(生気)になって土に還る。伐られた株、波に洗われた岸も痕跡として残す |
| 8 | 忠実さ | **数と場所は忠実、物語は演出**。区域内の頭数は密度に比例し、増減は生まれる・死ぬ・区域の外へ出入りする演出で合わせる。狩りは狼と鹿が重なるセルでだけ起きる。島の状態と矛盾するもの(減っているのに豊かに見える等)は見せない |
| 9 | 区域・性能 | **集落を中心に半径 8 セル**(約 17×17。民の林と舟の材が全部入る)。区域外は遠景(低解像度の島と海、霧)。デスクトップの Chrome(M シリーズの Mac 程度)で 60fps、動く個体は数百。スマホは対象外 |
| 10 | 必須の場面 | **舟が育つ過程**(着工 → 竜骨 → 肋 → 板 → 帆、民が材を運ぶ)、**舟の飛び立ち**(民が集い乗り込み、舟が浮いて水平線へ、その後の空の集落まで)、**種を放ったあと**(植えた鐘樹が芽吹く、疫病の霧が漂う等、自分の手が島に届いたことが見える)、**滅びの兆しと終わり**(帆を失う = 灯りが消え工事が止まる、海面が上がる、沈没で区域が水に沈む) |
| 11 | 調達 | **混成 + 絵の統一はシェーダ**。地面・岩・草の質感は CC0 素材(Poly Haven・ambientCG)。動物・鐘樹・舟・集落は AI の 3D 生成(Meshy/Tripo など、有料・要 API キー)→ Blender で整形・リグ・アニメ。出どころの違いは絵画調の光と色調(シェーダ・後処理)で揃える。最初に鹿 1 頭で試作して品質と費用を見る。公開リポジトリ(MIT)に同梱できるライセンスに限る |
| 12 | 受入 | **ムードボード → 比較画 → 観察セッション**。最初にキービジュアル 3〜4 枚(林の鹿の群れ、建造中の舟と集落、飛び立ち、沈む海岸)を承認してもらい、それを基準に各アセットを「基準画とゲーム内の並べ比較」で受入。最後に実際の空の舟を 1 回通して観察し、4 つの場面が出ることと「10 分見ていられるか」を手動で確かめる |

## デザインボードへの判断(2026-09-23 20:25、ユーザー)

ボード: https://claude.ai/artifact/ELLA1JjBSgZz5PeXTjaWs3(非公開、生成は `tools/gen-design-board.mjs`)

- 採用: 群れ v2・建造中 v1・飛び立ち v1・沈む海岸 v2。ただし案の間に決定的な差は無い(トーンの物差しとして使う)。
- **絵画的な写実のトーンは可**。ただしブラウザで動く小規模ポリゴンで動かす必要があるので、**デフォルメしたモデルと組み立て一式を試作するフェーズ**を入れる(M22-02)。
- **動物の造形は元の参照に合わせる**: `assets/textures/concept/{deer,wolf,rabbit}-angular.png`(ムー意匠: 月鹿の青緑の装甲板・シアンの継ぎ目・光る三日月の角、灰狼の珊瑚色と背のシアンの稜線、土兎の焦げ茶の耳先と光る六角の紋)。
  画風とトーンだけ揃える。基準画は Gemini 3 Pro Image に元の参照とキービジュアル(群れ v2)を渡して描き直した(2.5 Flash では参照に寄せると平板なままだった)。
- **モデルの解像度と精細度の基準は Nintendo Switch 初代世代の 3D ポケモン**。決定 0d の「高精細」はこの密度に読み替える(絵は基準画、形はこの密度)。
- キービジュアルの鹿は第 1 稿の自然な鹿のまま。ゲーム内の造形は基準画(元の参照)に従う。
