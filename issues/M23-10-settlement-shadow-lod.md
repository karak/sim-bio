# 集落の部品の影と遠距離版の軽量化

## What to build

集落の建物の磨き上げ(settle1、12ddb43)で石を格子の丸めた箱にし、苔・汚れ・目地を足した結果、次のように増えた。
- 近い形の三角形: 小屋 10,178 → 27,142、船台 1,982 → 17,902、石垣 948 → 5,002
- 集落の画: 31.7 → 44.2 万三角形。予算 150 万の内だが、増えた分の多くは影
- 小屋以外の部品は近い形で影を落とすので、海岸の画では集落の部品の影が 13.3 → 42.8 千三角形になった
- settlement.glb: 1.43 → 4.42 MB

ユーザーの指示(2026-09-26 12:28、原文):「影やLODといった軽量化をタスクに積むこと」

やること:
- 小屋以外の部品(灯り柱・立石・船台・石垣・L 字の石垣・衝立)の影を、遠距離版か影専用の形で落とす(小屋と同じ `shadowOnly` の仕組み、M23-04・M23-09)。
- 近い形を切り替える距離と、中間の段が要るかを見直す。
- glb の大きさを減らす(頂点色の精度、共有できる形のインスタンス化など)。
