# アート発注書 — 2D デザイン画像(3D デザイナー用の下絵)

- 目的: 3D モデル(glTF)を作る前の **2D デザイン画**。ローポリ化しやすいよう、形をはっきり、色数を絞る。
- 対象読者: ムー読者の中高生。失われた大陸、オーパーツ、予言、古代宇宙飛行士の雰囲気。
- 見た目の方針(設計書 §2 決定 14): セミリアルに拡張できる設計、初期は識別優先の単色ローファイ。
  → 今回の画像は **識別しやすいシルエットと色** を最優先。テクスチャの細密さは不要。
- 出力: PNG、正方形 1024×1024、背景は単色(白または薄いグレー)。ファイル名は下表の `assetId`。
- 保存先: `assets/textures/concept/<assetId>.png`(コンセプト画)。3D 化後は `assets/models/<assetId>.glb`。

```
Low-poly-friendly concept art for a browser ecosystem game. Clean silhouette, flat colors, 3-5 colors max,
no texture detail, single-color background (#F4F6F1), centered subject, 3/4 view for creatures and props,
isometric top-down for the island. Style: lost-continent (Mu/Atlantis) mystery for teenage readers,
ancient stone tablets, glowing crystals, but keep it bright and readable. No text in the image.
```
