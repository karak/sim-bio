# 光角鹿 (deer) 3D モデル 残課題

対象: `assets/models/deer.glb` / `.blend`、`tools/blender/deer.py`。中間成果物として利用する。
到達値: シルエット IoU 0.49、fur / dark / glow マスク IoU 0.42 / 0.31 / 0.21、色 ΔE76 は全パーツ < 1 (`deer-metrics.json`)。

### 1. 角の形が参照の「太い三日月」になっていない (glow IoU 0.21)
- 現状: 主幹を折れ線チューブ (半径 0.045→0) で外へ張り出させ上で内側へ戻し、内向きの枝を 1 本つけている。
  参照は主幹が太い C 字で、上端で二叉に分かれ、内側の枝も三日月形。参照の角はシルエットの 20% を占める。
- 対処案: 主幹を 8〜10 点の滑らかな折れ線にし半径を 0.05 で一定に近づける。上端の二叉を追加。枠座標→3D の換算
  (`fx ≈ 0.42·(x−y)+0.042`, `fy ≈ 0.97−0.59·z`) は `make_antler` のコメントに記録済み。

### 2. 深緑パネルの形が面単位で粗い (dark IoU 0.31)
- 現状: 胴の 16 頂点×25 リングの面のうち、参照の多角形に投影される面を塗っている (`paint_faces`)。境界がジグザグになる。
- 対処案: 胴のリングをパネルの輪郭に沿って配置する (輪郭の y 位置に断面を置く) か、塗り分け後に面を分割して境界を直線化する。

### 3. 頭と首が参照より小さく細い
- 現状: 頭長は合っているが顎が浅く、首は参照 (画面幅 0.13 H) より細い。耳は付け根位置と向きは合っているが小さい。
- 対処案: 頭の後半の rz を +0.03、首の前後径を +0.03。耳の長さ 0.24→0.28。

### 4. 脚が参照より太く、遠近で奥の脚が高く写る
- 現状: rabbit と同じく、50 mm・仰角 10° では奥の蹄が手前より約 0.03 H 高く写る (参照は地面線を揃えて描いている)。
- 対処案: 評価のみ平行投影にするか参考値扱い。

### 5. 収束色は比較スクリプトの照明前提
- rabbit と同じ (`rabbit-remaining-issues.md` #7)。glow は発光強度 0.3 で撮影した平均が参照 #A4FCF4 に合うよう補正した値。

### 6. 目の縁 (深緑) が小さく、口の線・鼻孔がない
- 参照の目は菱形に深緑の縁取り。現状はアーモンド形 2 層デカール。口の線 (dark の細い線) は未実装。
