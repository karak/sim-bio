# 観察画面の月鹿(M22-02 デフォルメ試作)

基準画 `assets/textures/board/creatures/deer.png`(承認済み)を、Switch 世代の 3D ポケモン程度の密度(丸めた形・なめらかな陰影)で起こした月鹿。
作り方は設計 §9 の A(`tools/blender` の部品集)。既存のローポリ鹿(`tools/blender/deer.py`)の意匠(青緑の装甲板・シアンの継ぎ目・三日月の角)を引き継ぎ、形は基準画の画素から測り直した。

## 実測(`observe_deer_check.py`、GLB を読み戻した値)

| メッシュ(ノード名) | 三角形 | 頂点 | 内訳(材質別の三角形) |
|---|---|---|---|
| `deer`(近 LOD、雄) | **3,126** | 2,311 | body 1,770 / glow 648 / plate 348 / hoof 260 / antler_base 100 |
| `deer_lod1`(群れ LOD) | **872** | 717 | body 494 / glow 208 / plate 90 / hoof 60 / antler_base 20 |
| `deer_doe`(雌、角なし、近 LOD と同じ密度) | 2,754 | 2,101 | body 1,770 / glow 356 / plate 348 / hoof 260 / antler_base 20(目の縁) |

- 予算(設計 §8: 近 3,000 / 群れ 900)に対し 近 +4%、群れ -3%。GLB は 525 KB(3 メッシュと 5 アクション込み)。
- 寸法: 単位 m。き甲(毛の背の線)1.41 m、角の先まで 2.90 m、角の幅 1.44 m、鼻先から尻 2.09 m。蹄の底が z = 0、前後の蹄の中点が原点(前蹄の先 -0.51、後蹄の先 +0.55)。
- 向き: Blender で正面 -Y → glTF で **+Z が正面、Y が上**。
- 3 つのメッシュは同じスキン(骨 28 本)を共有し、どれもシーンのルートに置く(アーマチュアの子にしないので glTF-Validator の NODE_SKINNED_MESH_NON_ROOT が出ない)。
- 1 頂点あたりの影響は最大 3 本、重みの合計はすべて 1。
- glTF-Validator(npm `gltf-validator`): **errors 0 / warnings 0**、アニメ 5、材質 5、スキンあり。

## 骨(28 本)

`root`(動かさない)・`pelvis`・`spine1`・`chest`・`neck1`・`neck2`・`head`・`jaw`・`ear_L/R`・`tail1/2`、
脚 4 本 × 4(前: `fl_upper/fore/cannon/hoof_{L,R}`、後: `hl_thigh/shin/cannon/hoof_{L,R}`)。角・目は `head` に固定。
どの骨もローカル X がワールド X(左右)を向くようにロールを揃えてあり、脚と背骨の曲げはローカル X 回りの回転だけで表せる。

## アニメーション(30 fps、その場。root と骨盤の水平位置は全フレームで 0)

| 名前 | 長さ | ループ | 中身 |
|---|---|---|---|
| `idle` | 4.0 s(120 f) | する | 呼吸(2 回)、首をゆっくり左右、1.0 s に左耳・2.7 s に右耳をはじく、2.0 s に尾を振る |
| `walk` | 1.2 s(36 f) | する | 4 拍の常歩(左後 → 左前 → 右後 → 右前、立脚 64%、歩幅 0.5 m)。首の上下、尾の揺れ |
| `run` | 0.6 s(18 f) | する | 回転ギャロップ(右後 → 左後 → 右前 → 左前、立脚 36%)。背の伸縮、耳を伏せる |
| `graze` | 5.0 s(150 f) | する | 0〜1.2 s 頭を地面へ、1.2〜3.8 s 顎を 3 回/秒で動かして食む(2.4 s に耳)、3.8〜5 s 上げる |
| `fall` | 2.0 s(60 f) | しない | 0〜0.6 s 前膝が折れる、0.45〜1.4 s 右側を下に横倒し、1.2〜2 s 首と頭が地に落ちて止まる |

- 脚は 2D の解析 IK(肩・股関節から球節)で、立脚中は蹄が地面に固定される。ループはどれも最初と最後のフレームが同じ。
- 全 28 骨を毎フレーム焼いてある(クリップを切り替えても前のクリップの姿勢が残らない)。`fall` は Three.js で `LoopOnce` + `clampWhenFinished`。

## 作り直しの記録

1. **1 回目**: 胴・首・頭・脚を断面のロフトで組み、装甲板を胴の軸から放射状に投影した。胴が長い筒、首が細い、頭と耳が小さい、角は外へ開くだけ、板は角を丸めすぎて楕円の塊、発光が白飛び。
2. **2 回目**: 基準画の側面と正面を画素で測り直した(き甲 176 px = 1.4 m、0.00795 m/px)。腹を 0.76 m まで下げて胸を深く、首を太く立て、頭を大きく。
   角を基準画どおりに作り直した(深緑の根元は頭頂から外・後ろへ、発光する主幹は外・後ろへ張り出してから上がり、先が前・内へ巻く三日月。前・内へ出て上を向く眉枝と中ほどの枝)。
   装甲板の輪郭を側面図の (y, z) で書き直し、胴・首・脚の付け根をまとめた殻へ投影するようにした(腰の板が腿へ、肩の板が上腕へかかる)。
3. **3 回目**: 板の角を丸めずに辺を割るだけにし(六角形の角を残す)、縁と面取りを硬いエッジ・頂をなめらかにした。板の色を明るく、喉から胸の前まで淡い色を続け、首と胴の継ぎ目の色の段差を消した。肩の上の板をき甲へ移した。
4. **4 回目**: アニメの向きの取り違えを直した(graze で首が背中側へ反っていた。ローカル X の正は「前・下へ倒す」)。fall の頭を起こし気味にロールして角が地面に刺さらないように、run は首を前へ伸ばす。
   角の根元を長く外へ、板の厚さ 7.5 cm。群れ LOD の蹄が地面の下へ 4 cm はみ出していたのを直し、き甲を 1.41 m に下げた。メッシュをアーマチュアの子から外して Validator の警告を 0 にした。

## 基準画との差(残り)

- **装甲板**: 基準画は面が立った宝石のような六角の板で、明るい面取りと暗い面がはっきり分かれる。モデルの板は輪郭と配置は合っているが、厚い平板に近く、面の明暗が弱い。肩の上の板が小さい。
- **塗り**: 基準画の筆の塗り(暖色のハイライト・寒色の影・毛並みの筆致)は無い。Blender の撮影は素の拡散光。トゥーンのランプ・縁の光・色調補正は Three.js 側の仕事(M22-02 の残り)。
- **胴の比率**: 胴が基準画より 1 割ほど長く、背の線が平ら、尻の丸みが弱い。
- **角**: 形と大きさは合っている。基準画の角は面の立った太い角で、モデルは六角断面のなめらかな管。撮影では発光が基準画より白寄り。
- **耳**: 雌の耳は基準画ほど大きく立っていない。
- **動き**: graze は首の付け根を 115° 曲げるので、寄ると付け根がつぶれる。fall の横たわった脚は折れて重なり気味。重みは骨までの距離で配っているので、run で肩の板が上腕と一緒にわずかに曲がる。
- **子鹿**: 作っていない(斑点は頂点色では粗く、装甲なし・別の毛色の材質が要る。必要なら 512² のテクスチャで別に起こす)。
- **民の雄の紐**: 作っていない(角の根元に結ぶ紐は民の個体の付け足しとして別ノードで足せる)。
- Three.js で読み込んで表示・アニメを再生する確認はまだ(この文書の検証は Blender の読み戻しと glTF-Validator まで)。

## 判定(試作としての所見)

造形の要点(黄褐色の体と淡い腹・喉、肩と腰の青緑の板と前縁の光る継ぎ目、腹の線と胸の V 字、深緑の根元から伸びる三日月の光る角、光る目、深緑の蹄、立った小さな尾)は、
4 方向とも基準画と同じ生き物として読める。密度は「角ばりを丸めたなめらかな形」に届いているが、基準画の絵としての質(板の面の立ち方、筆の塗り)には届いていない。
塗りを Three.js のシェーダで寄せたあとに、板の面の作り込みと胴の比率をもう一段詰めるか、AI の 3D 生成(設計 §9 の B)と比べるかをユーザーの美観チェックで決める。
