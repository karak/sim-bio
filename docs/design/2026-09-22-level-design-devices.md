## 2. 体験の芯(何で悩ませるか)

共通の芯: **回避装置は民の手で作られ、見守り手は「民をそこまで育てる / 急がせる」ことしかできない。装置の代償は生態(脈と森)で払う。**

### 2.1 迎撃の塔

150 年目に島を砕く星が落ちる。砕くには民が「星」に達し、さらに脈から輝石を蓄えて工事を終える必要がある。
星の門は群れ 4。群れを育てる間、民は勝手に脈を掘って土地を枯らす。止めさせるにも工事を進めるにも信仰 0.6 が要る。

プレイヤーの問い: 「脈を残したまま、群れを 4 に育てて星に届かせ、工事を終えられるか」。
放置は塔で頭打ちのまま脈を掘り尽くし、森が消え、150 年目に星が落ちる。急ぐ(止めよを使わない)と群れが 4 に届く前に脈が尽き、工事の輝石が無い。

### 2.2 空の舟

沈没は止められない(200 年)。帆の民は舟を作れるが、舟は材を食う。材は森と鐘樹。森は鹿が食い、鐘樹は 20 年かかる。
民が乗るには信仰 0.5。逃がした時点で部分勝利。

プレイヤーの問い: 「森を舟に回せば群れが飢えて民が減り舟が止まる。森を残せば舟が遅れて陸が沈む。何をいつ植え、いつ着工するか」。
放置は舟を作らず 180 年で群れが尽きる。舟だけ急ぐと材が無いまま止まるか、残った森を伐って群れが飢え帆を失う。

## 3. キーアイテム

### 3.1 気象塔(舞台装置、M10-01)

- 見守り手が建てる。門: 段階 ≥ 塔(6)、信仰 ≥ 0.6、集落の採掘半径に掛かる脈から `TOWER_CRYSTAL` を取れること。力 `TOWER_COST`。
- 効果: 半径 `TOWER_RADIUS` 内の rainScale / tempOffset を局所で上書きする。外は変わらない。
- 維持: 毎年 `TOWER_UPKEEP` を力から引く。払えなければ止まる(効果 0)。払えれば再開。
- 役割: 迎撃では雨で草 → 群れ。代償は輝石(工事の備蓄と取り合い)と力(放流と取り合い)。
- 舟の集落(帆、輝石なし)では **建たない**。舟のレバーは鐘樹・疫病・儀式(§9-4)。

### 3.2 迎撃の工事(舞台装置、M10-02)

- 星(7)に達すると始まる。民は脈から年 `WORKS_RATE` の輝石を備蓄(`crystalStock`)に積む(星の採掘率 0 をここに充てる。脈は減る)。
- 信仰 < 0.6 の年は進まない(工事が止まる。石板と HUD に出る)。
- 備蓄 ≥ `INTERCEPT_NEED` で `intercept` が可能。次の予定隕石を取り消し、備蓄を消費し、石板の節目が消え、年表に「星が砕けた」が並ぶ。
- 「星の砂を」の祈り(脈が開始比 0.1 未満)は応えられず、期限切れで信仰 −0.15 → 工事が止まる。**脈を早く枯らすほど後半が苦しい**(M9 の「儀式で安定した後の緊張の低さ」への答え)。

### 3.3 舟の建造(舞台装置、M10-03)

- `launch_ship`: 段階 ≥ 帆、信仰 ≥ 0.5、徴収半径 `LOAD_RADIUS[stage]` 内の材(森 + 鐘樹の密度和) ≥ `SHIP_FOREST_MIN` で着工。
- 着工後は毎年、材 × `SHIP_CUT` を伐って進みに積む(森・鐘樹の密度を実際に減らす)。`SHIP_NEED` で完成。材が無い年は進まない。
- 完成時に信仰 ≥ 0.5 なら民が乗り `escaped`。足りなければ乗らず、毎年再判定。
- 持ち出し: 生きている種(総量 > 0)の密度と CivState を JSON に書き出す。`escaped` の判定に「生きている種 ≥ 5」。
- 建造中も塔の燃料は同じ材を取る(`TIMBER_RATE`)。舟の伐採で鹿の餌(森)が減る。

### 3.4 鐘樹(生物の特性、既存 M8-10)

鹿に食われない、遅い、材になる。舟の **定着** のキーアイテム。陰で草が減り民の餌が細る(代償)。

### 3.5 勅令「止めよ / 再開せよ」と狼の間引き(既存 M9-03、疫病)

迎撃で脈を守り、群れを育てる既存のレバー。「狼を減らして」の祈りに応えれば信仰も上がる(このシナリオでは応えてよい)。

## 4. ループ

### 4.1 迎撃の塔(石の文明、1770、薪の蓄え 1400、信仰 0.5、隕石は 150 年目に島全体(半径 32))

1. 石板「百五十年目に星が落ちる。民が星に届き、輝石を蓄えれば砕ける」。民は 16 年で塔に上がり、頭打ちのまま脈を掘り続ける(石板: 脈 N 割)。
2. 儀式(草を 2 年ごとに集落へ)で信仰 0.6 → 「止めよ」。脈が止まる。
3. 群れを 4 に: 草の儀式、狼の祈りに応える(疫病)、気象塔の雨(輝石 −、力 −/年)。
4. 4 を超えたら「再開せよ」→ 9 年で星。その間も群れ 4 を保つ(割れば頭打ちで待つ)。
5. 星: 工事。信仰 0.6 を保つ(「星の砂を」が出る)。備蓄が満ちたら迎撃。
6. 150 年目: 取り消されていて段階 ≥ 塔なら alive。落ちれば dead(島全体が 0 になる)。

時間の見積り: 塔 16 + 儀式 20 + 群れ ? + 星 9 + 工事 `INTERCEPT_NEED / WORKS_RATE` ≈ 100。群れが §5 の感度を通ることが前提。

### 4.2 空の舟(帆の文明、2787、薪の蓄え 800、信仰 0.5、沈没 0.0006/年)

1. 石板「島は沈む。二百年で陸は三分の一。帆の民は舟を作れるが、材が要る」。森は 10 年で消える。
2. 材を作る: 鐘樹を集落の周りに(放流 4)。森を放つなら鹿を疫病で抑える。鐘樹の放流が儀式を兼ねる。
3. 30〜60 年: 材 ≥ `SHIP_FOREST_MIN` で着工。建造で材が減り、塔の燃料・鹿の餌と取り合う。
4. 完成 + 信仰 ≥ 0.5 → `escaped`(部分勝利)。遅れれば 175 年で集落が沈み、180 年で群れが尽きる。

## 7. 検討して捨てた案・保留

- **星の門(民 4.0)を下げる**: 係数いじり。「塔の重さ」で放置が星に届いてしまう。捨てる。
- **工事を塔(6)から始める**: 「星」の段階の意味が消える。保留(§5 の群れの感度が仕組みを変えても通らなければ再考)。
- **舟の材を森だけにする**: 森は 10 年で消え定着しない。鐘樹を材に含める。
- **舟を 1770(脈の上)に置く**: 帆の採掘で脈が枯れ 117 年で自壊(B2)。2787 に置く。
- **沈没 0.00075/年**: 2847 が 116 年で沈み、200 年の予言に対して早すぎる。0.0006 で 2787 が 175 年。
- **気象塔の門を帆に下げて舟でも使う**: 2787 に輝石が無く、門を下げても建たない。舟は気象塔を使わない(§9-4)。

## 9. 承認事項(ユーザー判断)

2026-09-22 13:52 承認(変更点なし)。

1. 迎撃の芯: 星の門(民 4.0)は据え置き。「止めよ」で脈を守りつつ群れを育てる(草の儀式・狼の疫病・気象塔の雨)のがループ。感度が通らなければ門を **10 年平均の民** で測る仕組みに変える(M9-00 と同型)。
2. 迎撃の工事(§3.2): 星に達した後に脈から備蓄に積む工程を新設し、信仰 ≥ 0.6 の年だけ進む。`intercept` は備蓄を消費して予定隕石を取り消す。
3. 舟(§3.3): 材 = 森 + 鐘樹(徴収半径内)。着工に下限、建造で毎年伐る、完成時に信仰 ≥ 0.5 で乗る。`escaped` は「生きている種 ≥ 5」を条件にする。集落 2787、沈没 0.0006/年、薪の蓄え 800。
4. 気象塔(§3.1): 門は塔(6)+ 信仰 0.6 + 輝石(チケットどおり)。舟の集落では建たないので、舟のレバーは鐘樹・疫病・儀式。気象塔の専用シナリオは M10 では持たない。
5. 両シナリオとも薪の蓄えで燃料を切り離す(迎撃 1400、舟 800)。
