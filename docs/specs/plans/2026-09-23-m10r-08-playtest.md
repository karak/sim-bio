# M10R-08 手動受入プレイテスト: 「空の舟」の作り直し(枯れにくい鐘樹・一定量の伐採・民の林)

2026-09-23。ブラウザ(Chrome、`npm run build && npx vite preview --port 5199` のビルド済み配信、size 64)で 2 回遊んだ記録。
操作は Chrome DevTools 経由でチップ(鐘樹・舟を作れ)と島のクリックを実際の UI イベント(canvas の click)として送り、100 倍速で年ごとに石板と HUD を読んだ
(M10R-06 と同じ方法。集落は空の舟 = セル (35, 43)。島のクリック位置は画面を 5 px 刻みで叩いてセル欄から 491 セル分の対応表を作って決めた。
標高で描画がずれるので直線の式では合わない)。放流は UI の環 1・0.5(力 4)。通し実行の台本(LD §8.9 計測 C)と同じ手が UI で打てるかを確かめるのが目的。

## チェックリスト

- [x] 予言に「舟は年に六の材を伐り、成るまで二十年」「林が痩せれば帆が落ち、舟は止まる」、舟の行に「年に 6 の材を伐って 120 まで進む(20 年)」が読める

## 2 回目: 林だけ(植えず)、10 年目に「舟を作れ」 — 着工できない(24 年目で打ち切り)

| 年 | HUD | 石板・操作 |
|---|---|---|
| 5 | 民 579 · 燃料 12 / 4年 · 信仰 0.47 / 上限 1.00 | 鐘樹 19。植えないので儀式が無く、信仰が 0.5 を割る |
| 10 | 信仰 0.45 · 燃料 12 / 4年 | 「舟を作れ」を押すが信仰 0.45 < 0.5 で着工しない(ボタンは灰色)。年表「10 年: 民が祈った: 狼を減らして」 |
| 20〜24 | 信仰 0.40 → 0.39 · 燃料 12 / 4年 · 鐘樹 15〜20 | 民の林だけで帆は落ちない(通し実行の「林だけ」は 175 年目まで帆が立ち、舟が無く沈む) |

- 見えた点: 林だけでは信仰が減衰して舟の門(0.5)を割り、着工すらできない。民の林は塔を養うが舟の材にはならない、が読める。
- 分かりにくかった点(M10R-06 の記録と同じ): 押しても拒まれた理由が舟の行に出ない(ボタンの灰色と信仰の数値から推し量るしかない)。→ 記録に残す。
