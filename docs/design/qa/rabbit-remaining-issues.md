# 土兎 (rabbit) 3D モデル 残課題

対象: `assets/models/rabbit.glb` (生成スクリプト `tools/blender/rabbit.py`)、commit `0aae098` 時点。
本モデルは中間成果物として利用する。以下は参照画像 `assets/textures/concept/rabbit-angular.png` との
定量比較 (`tools/blender/compare_ref.py`、方位 45°・仰角 10°) で残っている差分と、その判断・対処案。

## 残課題

### 1. 奥 (左) の耳の「折れ」を幾何で作れていない
- 現状: 奥の耳はねじらず直立させ、上部 45% だけ内側色で塗り分けている。参照ではこの部分は耳が折れて外面が見えている。
- 影響: 参照アングルでは一致するが、他アングルでは「先だけ濃い耳」に見える。
- 試したこと: 断面を軸まわりに 120°→0° へねじる方式。折れ目の四角面がねじれて潰れ、耳がくびれて見えたため不採用。
- 対処案: 耳の刃を斜めの折り線で 2 枚の平板に分け、上の板だけ前を向ける (紙を折る構造)。

### 2. 耳が左右非対称のポーズ
- 現状: 手前 (右) の耳は後ろへ 28°・外へ 8° 寝せてねじり 45°、奥 (左) の耳は直立でねじりなし (`make_ear` の引数)。
- 影響: ゲーム内で対称が必要な場合はそのままでは使えない。
- 対処案: `make_ear(1, 8, 28, 45, SMOOTH_TWIST, length=0.44)` を両耳に使えば対称になる (参照との一致度は下がる)。

### 3. 濃色 (dark) のマスク IoU が 0.06
- 現状: 参照の濃色は鼻以外ほぼ影 (前脚の間、腿の下)。モデルでは鼻と後ろ足の飛節 (かかと→腰の下腿) だけを濃色にしている。
- 影響: 材質では影を再現できないので、この指標は構造的に低いまま。色 ΔE は 0.31 で合っている。
- 対処案: 評価側で「影由来の濃色」を除外する (参照の濃色クラスを鼻・耳・飛節の連結成分に限定する) か、この指標は参考値扱いにする。

### 4. 足元の高さが参照と 0.1 (全高比) ずれる
- 現状: 参照は全ての足を同じ地面線に描いているが、50 mm・仰角 10° の透視では後ろ足が手前の前脚より約 0.1 高く写る (`RABBIT_DEBUG=1` のランドマーク出力で確認)。
- 影響: シルエット IoU の下限になっている (fy 0.9〜1.0 の行で不一致)。
- 対処案: 参照側の作画都合なのでカメラは変えていない。評価だけなら平行投影 (orthographic) カメラで比較する選択肢がある。

### 5. 発光 (glow) のマスク IoU が 0.33
- 現状: 六角模様の位置は参照の連結成分の実測から投影して貼っているが、胸の面が斜めなので隣接する六角が重なって塊に見える。
- 対処案: 胸の断面を参照どおり前面が平らな台形にして六角を広げる。デカール半径を 0.85 倍に縮める。

### 6. 奥の前脚が手前の前脚の左に見える
- 現状: 参照では奥の前脚は手前の前脚のほぼ真後ろに隠れる。モデルは奥の脚を 0.06 だけ後ろにずらして目立たなくしている。
- 影響: 完全に隠すには 0.16 後ろ (歩行ポーズ) にする必要があり、静止ポーズとして不自然なので見送り。

### 7. 収束した材質色は比較スクリプトの照明前提
- 現状: `rabbit-colors.json` の色は太陽光 2.5 + 白環境光 0.5、スペキュラ 0 での撮影平均が参照に合うよう補正した値。
- 影響: three.js 側の照明が異なると見え方が変わる。発光色の G は 255 で飽和しており、これ以上はエミッション強度で詰める必要がある。
- 対処案: ゲームのレンダラで同じ手順 (撮影→ΔE→比率補正) を回す。

### 8. 頭の三角形数が減っている
- 現状: 頭を 12 頂点から 8 頂点断面にした分を、デカールの三角形化で相殺している (合計 1863)。
- 影響: 目標 (旧 592 の 3〜5 倍 = 1776〜2960) の下限付近。
- 対処案: 胴のリング数を増やす (densify を 2 回) と約 +250。
