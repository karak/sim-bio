## 2. 体験の芯(何で悩ませるか)

共通の芯: **信仰は「星の振る舞いの予測可能さ」で決まり、祈りは「民が星に依存する入口」である。**
信仰は放っておけば減る。上げる道は 2 つ。(a) 祈りに応える(速い、楽、だが民は考えるのをやめる)。(b) 儀式 = 祈りと無関係な
同じ介入を規則正しく続ける(遅い、力を食う、だが民は自立したまま)。

### 2.1 祈りに応えるな

民は困るたびに祈る(草が痩せれば「雨を」、狼が増えれば「狼を減らして」)。応えれば信仰が上がって楽になる。
だが **一度でも応えれば民は考えるのをやめる**(その場で滅び)。応えずに信仰を保つには、

- 祈りと無関係な儀式(たとえば苔を 3 年ごとに集落へ放つ)を 100 年続けるか、
- 祈りが生まれる条件そのものを先回りして潰す(祈りが出る前に草を放つ、狼が増える前に間引く)。

プレイヤーの問い: 「祈りに応えるのは簡単だ。応えずに、民が星を信じ続けるにはどうするか」。
放置は信仰が減衰して内乱で崩れる。気まぐれ(毎年違うことをする)は信仰が下がる。応えれば滅ぶ。

### 2.2 霊脈枯れ(簡易版)

民は勝手に掘る。掘るほど霊脈(地下の輝石)が細り、その土地の **分解の効きが落ちて生気が戻らなくなる**。
止めさせるには「採掘を止めよ」に民が従う信仰(≥ 0.6)が要り、信仰を上げるには年数がかかる。
輝石が尽きかけると民は「星の砂を」と祈るが、M9 では応えようがない(無視で信仰が削られる)。
**早く止めれば残った霊脈で生気が戻る。遅ければ苔を放っても戻らない。**

プレイヤーの問い: 「民に従わせるだけの信仰を、霊脈が尽きる前に作れるか。祈りに応えて速く上げるか、儀式で堅く上げるか」。
放置は生気が枯れて文明が自壊する。苔だけ放っても霊脈が尽きた土地では戻らない。信仰が足りないうちに止めよと言っても民は聞かない。

## 3. キーアイテム

### 3.1 祈りの印(舞台装置、M9-02)

集落から石板に届く要求。条件 → 種類 → 応え方を 1 対 1 に決める。同時に 1 つ、期限 5 年、解決後は 3 年は次が出ない。

| 種類 | 出る条件(集落の支え半径 8) | 応えと数える介入 |
|---|---|---|
| 雨を | 草の密度平均が閾値未満 | `set_climate` で雨を今より増やす、または半径内への草の放流 |
| 狼を減らして | 捕食者の総量 / 民の総量が閾値超 | 半径内への疫病 |
| 星の砂を | 採掘半径内の輝石が開始の閾値割未満 | **M9 では応えられない**(M11 星砂層で追加)。出るだけで期限切れ −。霊脈枯れの圧になる |

応えれば信仰 +(FAITH_ANSWER)、期限切れで −(FAITH_IGNORE)。ログ `scenario.prayer`(issued / answered / ignored)。

### 3.2 霊脈(舞台装置、M9-03 の一部として新設)

輝石は地下で土地の生気を支える。セルごとに `depletion = 1 − crystal / crystal0`(開始時に輝石があったセルだけ、他は 0)を
半径 3 でぼかした `veinLoss` を持ち、分解率を `k = BASE + BOOST × 分解者 × (1 − VEIN_LOSS × veinLoss)` に落とす。
輝石が無かった土地は今までどおり(既存シナリオの平衡は変わらない)。掘り尽くした土地では苔がいても生気が戻らない。

### 3.3 勅令「採掘を止めよ / 再開せよ」(舞台装置、M9-03)

石板の操作。`Command { type: 'civ_edict', edict: 'stop_mining' | 'resume_mining' }`。**信仰 ≥ 0.6 のときだけ効く**。
効いた年から採掘が 0(段階も進まない)。負荷(伐採・生気の消費)は残る。力は消費しない(言葉であって行為ではない)。
信仰の「同じ種類の介入」には数えない。

### 3.4 民の特性: 委ねと内乱(M9-03)

- **委ね**: 祈りに応えられると民は考えるのをやめる。「祈りに応えるな」ではこれが敗北条件(Condition `prayers_answered { max: 0 }`)。
- **内乱**: 信仰 < 0.3 が 3 年続くと集落の民(支え半径 8)が半減し段階 −1。信仰は 0.4 に戻す(3 年ごとに連鎖しないため)。ログ `sim.civ.unrest`。

(儀式 = 信仰の値の規則そのもの。M9-01 で「同じ種類が 10 年内に 3 回で +、3 種類以上が混ざると −、災害は −、毎年減衰」。)

## 4. ループ

### 4.1 祈りに応えるな(歌の文明、seed 42、size 64。集落は採掘半径 3 に輝石が無い場所 → 段階が進まず燃料も要らない)

1. 石板が信仰 0.50 と「祈りに応えれば民は考えるのをやめる」を告げる。
2. 鹿の 9 年周期の谷で集落の草が痩せ、「雨を(残り 5 年)」が届く。応えたくなる。
3. 応えずに待つと期限切れで信仰が落ちる。何もしなければ減衰で 0.3 を割り、内乱で民が半減して段階が落ちる。
4. 儀式(同じ放流を 3 年ごと)を続ければ信仰が上がる。力は年 12、放流 4 なので続けられるが、祈りが重なる年は足りない。
5. 先回り(草が痩せる前に草を放つ、狼が増える前に疫病)なら祈り自体が出ない。だが疫病は災害なので信仰を削る。
6. 100 年目: 一度も応えず、段階 ≥ 1 を保っていれば生き延び。応えた瞬間、または段階 0 で滅び。

### 4.2 霊脈枯れ(簡易版)(石の文明、輝石の鉱脈の上。薪の蓄え(fuelStock)で 100 年は燃料が要らない)

1. 石板が信仰 0.50、「民は掘り続ける。霊脈が尽きれば生気は戻らない。止めよと言えるのは民が星を信じたときだけ」を告げる。
2. 採掘が進む(石 → 帆 → 塔と上がり、掘る速さと半径が増す)。集落の生気がゆっくり落ち、輝石が減ると「星の砂を」が届く(応えられない)。
3. 信仰を上げる: 祈り「雨を」「狼を減らして」に応える(+0.15、速い)か、儀式を続ける(+0.05/年、堅い)。
4. 信仰 0.6 で「採掘を止めよ」。効けば採掘 0。残った霊脈の分だけ分解が効くので、苔を放てば生気が戻る。
5. 遅すぎれば(輝石が開始の 1 割未満)苔を放っても戻らない。生気 < 0.1 が続いて文明が衰退し、段階 0 で滅び。
6. 100 年目: 集落の生気(支え半径 8 の平均、直近 10 年)≥ 0.3 かつ段階 ≥ 1 なら生き延び。

## 7. 検討して捨てた案・保留

- **委ね(reliance)の累積**(応えるほど祈りが速く、無視の痛みが増す): 「祈りに応えるな」は「一度でも応えれば滅び」で足りる。累積は M18(複数の滅び)で。
- **輝石が無い土地にも霊脈の効きを掛ける**(分解率を輝石の絶対量で決める): 島の大半は輝石 0 なので生気の平衡が島全体で変わり、既存 20 本の校正が崩れる。開始比の枯渇(depletion)だけに掛ける。
- **霊脈枯れを塔(6)で始める**(シナリオ表の原案): 燃料 6/年が要り、火と樹の話が混ざる。簡易版は石(4)+薪の蓄えで燃料を切り離し、塔版は M13(霊脈の線・熱との連動)で。
- **勅令に力の値段を付ける**: 信仰の門があるので値段は要らない。値段を付けると「力があれば言える」に見える。
- **祈りに応えるなで「歌」より上の文明を使う**: 採掘で段階が進むと燃料が要って衰退の理由が混ざる。輝石の無い集落で歌に固定。

## 8. 文明の自然発生条件の見直し(M9-00)

実測(§1)から、島全体の振幅比と半径 3 の植生は既定の島で構造的に満たせない。仕組みを次に変える(閾値は据え置き)。

- **安定は地域で測る**: 候補セル(その種の密度最大の陸セル)の支え半径 8 の総量を年ごとに履歴に取り、その振幅比 < `EMERGE_AMPLITUDE`(0.15)。実測では年 30 以降 0.08〜0.11 で満たす。候補が年ごとに動くと履歴が繋がらないので、候補は前年から 8 セル以内に留まっている間だけ履歴を継ぐ(離れたら履歴を捨てる)。
- **余剰は「掘るものがある」で測る**(世界観 §1.5「知性は余剰から生まれ、遺産を掘る」): 候補の採掘半径 `MINE_RADIUS[1]`(2)以内に輝石があること。輝石が無ければ段階 1 で止まるだけなので、発生の条件に含める。
- **植生の閾値は支え半径 8 の平均**で測り、`EMERGE_VEGETATION` は 0.4 のまま **候補の半径 8 の植生平均 ≥ 0.4 × 島の陸の植生平均** (相対値)に読み替える。密度最大点が採食圧最大点になる構造上、絶対値では届かない。
- 受入: seed 42 / size 64 / 全種で鹿の文明が 60 年以内に発生する(単体テスト、`sim.civ.emerged`)。草だけの世界の既存テスト(10 年目に発生)は変えない。既存の通し実行 20 件が通る(既存シナリオは stage を指定して始めるので発生判定を通らない)。

## 9. 承認事項(ユーザー判断)

1. §2 の芯: 「祈りに応えるな」は **応えた瞬間に滅び**、信仰は儀式か先回りで保つ。
2. §3.2 霊脈: 分解率を **開始比の枯渇** で落とす(輝石の無い土地は変えない)。
3. §4.2 霊脈枯れ(簡易版)は **石(4)+薪の蓄え** で始め、燃料を切り離す。
4. §8 発生条件の読み替え(地域の安定、輝石の有無、相対の植生)。閾値の数値は据え置き。
