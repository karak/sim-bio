# M10 手動受入プレイテスト: 「迎撃の塔」「空の舟」

2026-09-22。ブラウザ(Chrome、`npm run build && npx vite preview --port 5199` のビルド済み配信、size 64)で 3 回遊んだ記録。
操作は Chrome DevTools 経由でチップ(草・鐘樹・勅令・星を砕け・舟を作れ)と島のクリックを実際の UI イベント(canvas の click、
Three.js のレイキャストで拾われる)として送り、100 倍速で年ごとに石板と HUD を読んだ。集落の画面座標は島を細かく叩いてセル欄で確かめた
(迎撃の塔 = セル (42, 27)、空の舟 = セル (35, 43))。

## チェックリスト

- [x] 予言・節目・力の残量が最初から石板に見える
- [x] 星の門(半径 12 の民 4.0・信仰 0.8)が石板の節目で読め、塔で止まっている理由が HUD から分かる
- [x] 星になると HUD に「工事 備蓄 / 3」が出て、備蓄が満ちると「星を砕け」が押せ、押すと節目が消えて年表に「星が砕けた」
- [x] 舟の行(「舟を作れ」+ 門の説明)が見え、建造中は「舟 進み N / 120」、完成して飛ぶと「次の島へ」と「持ち出しを保存」
- [x] 少なくとも 1 回は負け、理由が石板の文言で分かる

## 1 回目: 迎撃の塔 — 10 年は石板を読み、そこから草の儀式。塔で「止めよ」、信仰 0.8 で「再開せよ」、備蓄が満ちるたび「星を砕け」 — 島は生き延びた

| 年 | 力 | HUD | 石板・操作 |
|---|---|---|---|
| 0 | 40 / 120 | 石(4) · 進み 1% · 信仰 0.50 | 予言と節目 5 つ(16 / 45 / 60 / 100 / 140 年目)。**「舟を作れ」の行も並ぶ**(この石板では要らない) |
| 10 | 68 | 帆(5) · 燃料 1367 · 信仰 0.45 · 生気 89% | 「祈り: 狼を減らして」。応えず、草を 2 年ごとに集落 (42, 27) へ |
| 20 | 75 | 塔(6) · 進み 28% · 信仰 0.69 · 生気 76% · **採掘 止** | 塔に着いた年に 0.6 を超えていたので「止めよ」。民は従った |
| 27〜30 | 80 | **星(7)** · 信仰 1.00 · 生気 66% · 工事 0.2 / 3 | 0.8 で「再開せよ」→ 9 年で星。HUD に「工事 備蓄 / 3」、「星を砕け」の行が出る(沈んだまま) |
| 44 | 84 | 工事 3.0 → 0.2 | 「星を砕け」が押せる。年表「星が砕けた(60 年目の星は落ちない)」、節目から 60 年目が消える |
| 59 | 87 | 生気 37% | 二度目。「100 年目の星は落ちない」 |
| 74 | 87 | 生気 27% | 三度目。「140 年目の星は落ちない」。節目は空になる |
| 80〜 | 84 → 57 | 星(7) · 信仰 0.93〜1.00 · 生気 11% · 工事 2.0 / 3 | 脈が尽き、工事は 2.0 で止まったまま。「祈り: 星の砂を」が 5 年ごとに出て無視され、信仰が 1.00 → 0.89 → 儀式で戻る |
| 150 | 57 | 星(7) · 民 312 · 燃料 174 / 9年 | **島は生き延びた / 星を 3 回砕いた / 文明の段階 7(星)**。介入 73 回、使った力 280 |

- 見えた点: 塔に着いた年(16〜20 年目)に「止めよ」を出せるかが勝負で、HUD の「採掘 止」と節目「星には群れ(半径十二)と信仰 0.8 が要る」で理由が読める。三度目のあとは脈が尽き、生気 11%・工事 2.0 で止まったまま 70 年が過ぎる(LD §8.2 のとおり「島が死んで星だけ砕く」)。
- 分かりにくかった点: **「舟を作れ」の行が迎撃の塔にも出る**(帆・信仰 0.5・材 6 の説明つき)。逃がす条件の無い石板では気が散る。→ 修正: 逃がす条件(escape)のある石板と自由モードだけ舟の行を出す(`Hud.setShipEnabled`、E2E: test-intercept で `#hud-ship` が隠れる)。
- 悩む余地: 三度目のあとの 70 年は「星の砂を」を無視し続けるだけ。儀式が回っていれば信仰は 0.89 → 1.00 に戻り、内乱の気配は無い。

## 2 回目: 空の舟 — 開始時の森で着工し、森を 2 年ごとに集落へ放ち続ける — 島は滅びた

| 年 | 力 | HUD | 石板・操作 |
|---|---|---|---|
| 0 | 40 / 120 | 帆(5) · 信仰 0.50 | 予言と節目 3 つ(10 / 100 / 175 年目)。「舟を作れ」が押せる(開始時の森が材 6 を満たす)ので即着工 |
| 10 | 49 | 信仰 0.74 · 生気 100% | 舟 進み 5.1 / 120。「祈り: 狼を減らして」(応えない、取り下げになる) |
| 20〜80 | 57 → 80 | 信仰 1.00 | 進み 8.8 → 25.2(10 年に 2.7〜3.7)。放った森は鹿に食われ、材はほとんど残らない |
| 100 | 79 | 民 55 | 進み 30.2。節目「陸は半ば」。**警告は何も出ない** |
| 150 | 63 | 民 39 | 進み 36.5 |
| 160〜 | 57 → 26 | 民 146 → 0 · 燃料 160 → 40 | 進みが **36.8 で止まる**(集落の周りが沈み、材が無い)。175 年目に集落が沈み、民 0 |
| 200 | 26 | 火(2) · 民 0 · 信仰 0.66 | **島は滅びた / 予言の年に条件を満たせず: 舟はまだ飛んでいない**。介入 100 回、力 400、陸地率 9% |

- 見えた点: 予言の「森は鹿が食い尽くし、放ってもすぐ消える」がそのまま起きる。石板の節目「鐘樹は鹿に食われない」を読んでいれば避けられる。
- 分かりにくかった点: **舟が間に合わないことを石板が告げない**。100 年目に進み 30 / 120 で、残り 100 年に 90 は要るのに警告が無い。160 年目からは進みが止まっているのに、それも分からない。→ 修正: 警告「舟の進みが止まっている(材が無い)」と「このままでは舟が間に合わない(進み N / 120、年に M)」(`warnings.ts`)。

## 3 回目: 空の舟 — 鐘樹を集落の周り 3 か所に毎年放ちながら着工 — 次の島へ

| 年 | 力 | HUD | 石板・操作 |
|---|---|---|---|
| 0 | 40 / 120 | 帆(5) · 信仰 0.50 | 即着工(開始時の森で材 6 は足りる)。鐘樹を (35, 43) と両隣の 2 セルに毎年(4 × 3 = 12 / 年) |
| 5 | 6 | 信仰 0.71 | 舟 進み 15.4 / 120。**力が底をつき**、以後は年に 1〜2 回しか放てない(収入 8 前後) |
| 10〜50 | 2〜5 | 信仰 0.92 → 1.00 · 生気 100% | 進み 25.9 → 100.2(10 年に 18〜20)。「祈り: 狼を減らして」は取り下げが続く |
| 60 | 5 | 帆(5) · 民 222 | 舟は飛び立った。**次の島へ / 7 種と民を次の島へ逃がした**。「持ち出しを保存」が出る。介入 48 回、力 192 |

- 見えた点: 鐘樹は放った分がそのまま材になり、2 回目(森)の 5 倍の速さで進む。力が上限で、放てる本数は収入(陸が減るほど細る)で決まる。
- 見えた点: 舟が飛ぶと石板が「次の島へ」になり、「持ち出しを保存」のボタンが並ぶ(cargo.json)。
- 分かりにくかった点(共通): **hidden の行が見えたまま**だった。`.row { display: flex }` が `hidden` 属性に勝ち、勅令・迎撃・舟の行は「隠す」つもりでも表示されていた(自由モードで文明が無くても勅令の行が出る、星になる前から「星を砕け」が並ぶ)。→ 修正: `[hidden] { display: none !important; }`(hud.css)。E2E: test-intercept で舟の行が隠れる。

## まとめ

- 3 回中 1 回負け(空の舟、森だけ)、理由は「予言の年に条件を満たせず: 舟はまだ飛んでいない」と予言の一文(森は鹿が食い尽くす)で分かる。2 回生き延び(迎撃の塔: 儀式 + 止めよ + 三度砕く。空の舟: 鐘樹)。
- 直した表示: 逃がす条件の無い石板で舟の行を隠す。hidden の行が display:flex で見えていたのを直す。舟の警告 2 つ(止まっている / 間に合わない)。
- 気づき(校正の候補、記録に残す): 迎撃の塔は三度目のあと 70 年が「星の砂を」を無視するだけ。空の舟は鐘樹を知れば 60 年で終わり、沈没(175 年)の緊張は「知らない」ときにしか効かない。UI の放流(半径 1)はヘッドレスの環(半径 3)より 4 倍細く、力が縛りになる。
